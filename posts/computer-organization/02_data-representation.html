编码

  • 动词层面：是按照一套预先约定、标准化的映射规则，将人们熟悉的数据形式（如数值、字符、表、图、音频、视频等），转换为计算机能够存储、传输、处理的符号格式（计算机场景下绝大多数为二进制格式）的过程。
  • 名词层面：特指上述这套约定好的映射规则体系本身，比如我们常说的 UTF-8 编码、GBK 编码、H.264 编码，这里的 “编码” 就是指可落地执行的标准规则。
编码类型核心用途典型示例
数值编码解决整数、小数的计算机二进制表示原码 / 反码 / 补码、IEEE 754 浮点数编码
字符编码实现人类文字、符号到二进制的映射ASCII、GBK、UTF-8、UTF-16
多媒体编码压缩并转换图像、音频、视频数据JPEG/PNG（图像）、MP3/AAC（音频）、H.264/H.265（视频）
结构化数据编码转换表格、JSON 等业务结构化数据，提升传输存储效率Protocol Buffers、Avro、MessagePack
专用场景编码满足特定计算机场景的需求机器指令编码、CRC 纠错编码、曼彻斯特编码

数据在计算机中以二进制的形式进行表示。例如：数字、字符串、表、图、音频、视频等数据都需要输入设备转换成二进制数据才能在计算机内部进行存储和处理。

主要来看数值数据在计算机内部的表示。

一段数值数据的二进制编码在计算机内部可能表示的内容有：无符号数、有符号整数、有符号纯小数（纯小数：整数部分为0的小数）、有符号带小数（带小数：整数部分不为0的小数）。

整数和纯小数的小数点位置是固定的

整数的小数点位置固定在数值最低位的右侧

而纯小数的小数点固定在符号位右侧，数值最高位的左侧

因此整数和纯小数也被称为定点数

对于带小数的小数点位置并不是固定的，而是可以左右移动的又称为浮点数

计算机内部数值数据的表示格式（机器码）

假设一个数，整数部分有n位，用小写字母b表示比特，而其下标用来表示不同的数位，其中b0为最低位，bn-1为最高位，小数部分有m位，其中b-1为最高位，b-m为最低位。

这是无符号数的格式

真值

真值是相对于机器码而言的，指用 “+” 或 “-” 号标注正负，后跟数值本身来表示其真实大小 的数。真值可以用任意进制表示，一般采用十进制和二进制。

举个例子：

假设我们有一个8位的机器数：1000 0101

  1. 若该机器数是“原码”表示
    • 最高位 1 代表符号为负，后面的 0000101 代表数值为 5。
    • 那么，它对应的真值是：-5。
  2. 若该机器数是“补码”表示
    • 根据补码转原码的规则（减1再取反），该二进制序列代表的数值是 -123。
    • 那么，它对应的真值是：-123。

计数制

  1. 古老的计数方式
    • 一一对应
    • 缺点：读、写、核对，极其耗时耗力、极易出错；几乎无法表示万级、亿级的数字；没有运算的概念；计数与实物绑定，无法流通。
  2. 不同符权的计数方式
    • 用特殊的符号来代表一定数量（也就是计数符号有了权重，符权）
    • 缺点：由于没有位权，计数只能用符号累加，导致表示大数时符号过长或需要不断创造新符号；运算极其复杂。
  3. 不同符权+不同位权的计数方式（进位计数）
    • 符号有权重（符权），且符号的位置也有了权重（位权）
    • 例如：975.36 = 9x10² + 7×10¹ + 5×10⁰ + 3×10⁻¹ + 3×10⁻²

常用的进位计数制：二进制（Binary）、八进制（Octal）、十进制（Decimal）、十六进制（Hexadecimal）

数码：用来表示数的基本符号。
例如：十进制数码：0~9；二进制数码：0,1；八进制数码：0~7；十六进制数码：0-9,A-F。

基数：每个数码位所用到的不同符号的个数。二进制r=2，八进制r=8，十进制r=10，十六进制r=16。

位权：每个数位所对应的权重，位权 = 基数的位置次方。

进位：当某一数位上的数值达到该进制的基数时，就向相邻的高位进 1，同时该数位归零的计数规则。

进制数的书写表示方法

十进制数：\((数)_{10}或数D\)；二进制数：\((数)_{2}或数B\)；八进制数：\((数)_{8}或数O\)；十六进制数：\((数)_{16}或数H\)。

以上进制，十进制方便人的使用。二进制方便计算机的使用。

  • 计算机适用二进制的原因：方便用具有两个稳定状态的物理器件表示；0,1正好对应逻辑值假、真，方便实现逻辑运算；可很方便地使用逻辑门电路实现算术运算。

八进制和十六进制则是为了二进制数的书写和阅读方便。

什么是原码、反码、补码、移码

原码、反码、补码、移码是按不同规则编码出的二进制数。

为什么要有原码、补码、反码、移码，为什么不直接都用普通的二进制来表示数据呢？

计算机运算核心是加法器，有符号数需要考虑正负号，因此需要用二进制编码同时表示正负与大小，并使减法能用加法器完成。于是有了原码、补码、反码、移码。

定点数机器码的格式（符号位、数值位、符号位与数值位的分割）

对于原码，符号位为0表示正数，1表示负数，数值位为真值的绝对值。

原码的表示思想

真值→原码举例：

定点整数：\( x = +11110 \), \([x]_{\text{原}} = 0,11110\)；\( x = -11110 \), \([x]_{\text{原}} = 1,11110\)。
定点小数：\( x = +0.11101 \), \([x]_{\text{原}} = 0.11101\)；\( x = -0.11101 \), \([x]_{\text{原}} = 1.11101\)。

定点整数的原码定义：假设真值x为定点整数，n为数值位的位数，

$$ [x]_{\text{原}} = \begin{cases} x, & 0\leq x <2^n \\ 2^n-x = 2^n+|x|, & -2^n < x \leq 0 \end{cases} $$

例如：\( x = -11110 \), \([x]_{\text{原}} = 2^4 + 11110 = 10000 + 11110 = 1,1110\)。

定点小数的原码定义：

$$ [x]_{\text{原}} = \begin{cases} x, & 0\leq x <1 \\ 1-x, & -1 < x \leq 0 \end{cases} $$

例如：\( x = -0.1101 \), \([x]_{\text{原}} = 1 + 0.1101 = 1.1101\)。

原码优缺点：表示简单直观，但0有两种表示，符号位不能直接参与运算。

模和补数

时钟例子：时针从6拨到2，逆时针4格或顺时针8格，-4和+8等价。模数M=12，补数定义为a ≡ b (mod M)。

补码的表示思想：负数的补码等于模数加上该负数本身（模数为最高位进位的位权值）。

定点整数的补码定义：

$$ [x]_{\text{补}} = \begin{cases} x, & 0\leq x <2^n \\ 2^{n+1}+x = 2^{n+1}-|x|, & -2^n \leq x < 0 \end{cases} $$

例如：\( x = -(101010)_2 \), \([x]_{\text{补}} = 2^8 + (-1010101) = 1,1101011\)。

定点小数的补码定义：

$$ [x]_{\text{补}} = \begin{cases} x, & 0\leq x <1 \\ 2+x, & -1 \leq x < 0 \end{cases} $$

例如：\( x = -0.0101 \), \([x]_{\text{补}} = 2 - 0.0101 = 1.1011\)。

补码优点：减法转加法，0只有一种表示，符号位可直接参与运算；缺点：表示相对复杂。

负数的原码→补码：符号位不变，数值位取反，末位加1。中间过程即反码。

反码的表示思想

正数反码与原码相同；负数反码：符号位为1，数值位取反。

反码优缺点：符号位可参与运算，但需循环进位，且0有两种表示。

移码的表示思想

移码用于定点整数，\([x]_{\text{移}} = x + 2^n\)，范围 \(-2^n \leq x < 2^n\)。
例如：\( x = +1010110 \), \([x]_{\text{移}} = 1,1010110\)；\( x = -1010110 \), \([x]_{\text{移}} = 0,0101010\)。

移码优点：0只有一种表示，保持大小顺序，最小真值为全0，最大为全1。

为什么需要浮点数

带小数用定点表示会溢出或损失精度，比例因子方法麻烦。浮点数采用科学计数法形式：\( N = r^E \times M \)。

浮点数的表示格式：阶码E和尾数M。阶码位数决定范围，尾数位数决定精度。

浮点数扩大了表示范围：例如8位二进制数，3位阶码5位尾数时最大值约480，而定点数最大127。

上溢：阶码大于最大阶码；下溢：阶码小于最小阶码，通常按机器0处理。

规格化：使尾数最高数值位为有效值（如基数2时尾数最高位为1），表示唯一且精度最高。

IEEE 754 浮点数标准

32位单精度（float）：符号1位，阶码8位（移码，偏移127），尾数23位（原码，隐藏1）。
64位双精度（double）：符号1位，阶码11位（偏移1023），尾数52位。
