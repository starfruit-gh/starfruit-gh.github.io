（六）图

图的定义

图（Graph）：由两个集合 V 和 E 组成，记为 G = (V, E)。

  • V 是顶点（Vertex）的有穷非空集合。
  • E 是边（Edge）的有穷集合。

图的顶点集合不能为空，边集合可以为空。线性表可以是空表，树可以是空树，但图至少要有一个顶点。

  • 无向边：如果顶点 \(V_i\) 到 \(V_j\) 之间的边没有方向，则称这条边为无向边，用无序偶对 \((V_i,V_j)\) 来表示。
  • 无向图：如果图中任意两个顶点之间的边都是无向边，则称该图为无向图。
  • 有向边：如果从顶点 \(V_i\) 到 \(V_j\) 之间的边有方向，则称这条边为有向边，也称弧（Arc），用有序偶对 \(<V_i,V_j>\) 来表示，\(V_i\) 称为弧尾（Tail），\(V_j\) 称为弧头（Head）。
  • 有向图：如果图中任意两个顶点之间的边都是有向边，则称该图为有向图。

举个例子：

  • V = {A,B,C,D}
  • E = {(A,B),(A,C),(B,C),(B,D)}
  • 无向图的边用圆括号表示，(A,B) 等同于 (B,A)。
  • V = {A,B,C,D}
  • E = {<A,B>,<A,C>,<B,C>,<B,D>}
  • 有向图的边用尖括号表示，<A,B> 不等于 <B,A>。

图的术语

  • 简单图：在图中，若不存在顶点到其自身的边，且同一条边不重复出现，则称这样的图为简单图。
  • 无向完全图：在无向图中，如果任意两个顶点之间都存在边，则称该图为无向完全图。含有 n 个顶点的无向完全图有 \(\frac{n(n-1)}{2}\) 条边。
  • 有向完全图：在有向图中，如果任意两个顶点之间都存在方向相反的两条弧，则称该图为有向完全图。含有 n 个顶点的有向完全图有 \(n(n-1)\) 条边。
  • 稀疏图和稠密图：有很少条边或弧的图称为稀疏图，反之称为稠密图。这里稀疏和稠密是模糊的概念，都是相对而言的（例如 \(e < \log_2 n\)）。
  • 权和网：图的每条边可以标上具有某种含义的数值，该数值称为该边上的权。这些权可以表示从一个顶点到另一个顶点的距离或耗费。这种带权的图通常称为网。
  • 子图：假设有两个图 \(G = (V, E)\) 和 \(G' = (V', E')\)，如果 \(V' \subseteq V\) 且 \(E' \subseteq E\)，则称 \(G'\) 为 \(G\) 的子图。
  • 邻接：有边/弧相连的两个顶点之间的关系。
    • 在无向图中，如果图中存在边 \((v_i, v_j)\)，则称顶点 \(v_i\) 和 \(v_j\) 互为邻接点。
    • 在有向图中，如果图中存在边 \(<v_i, v_j>\)，则称 \(v_i\) 邻接到 \(v_j\)，\(v_j\) 邻接自 \(v_i\)。
  • 依附(关联)：边/弧与顶点之间的关系。
    • 如果图中存在边 \((v_i, v_j)\) 或 \(<v_i, v_j>\)，则称边 \((v_i, v_j)\) 或 \(<v_i, v_j>\) 依附于顶点 \(v_i\) 和 \(v_j\)，或者说边 \((v_i, v_j)\) 或 \(<v_i, v_j>\) 与顶点 \(v_i\) 和 \(v_j\) 相关联。
  • 度、入度、出度：顶点 \(ν\) 的度是指和 \(ν\) 相关联的边的数目，记为 \(TD(V)\)。在有向图中，顶点 \(v\) 的度分为入度和出度。入度是以顶点 \(v\) 为头的弧的数目，记为 \(ID(v)\)；出度是以顶点 \(v\) 为尾的弧的数目，记为 \(OD(v)\)。顶点 \(v\) 的度为 \(TD(v) = ID(v) + OD(v)\)。一般地，如果顶点 \(v_i\) 的度记为 \(TD(v_i)\)，那么一个有 \(n\) 个顶点，\(e\) 条边的图，满足：\(e = \frac{1}{2} \sum\limits_{i=1}^{n} TD(v_i)\)。
  • 路径：在无向图中，从顶点 \(v\) 到顶点 \(v'\) 的路径是一个顶点序列 \((v = v_{i,0},v_{i,1},...,v_{i,m} = v')\)，其中 \((v_{i,j-1}, v_{i,j}) \in E\)，\(1 \le j \le m\)。如果 \(G\) 是有向图，则路径也是有向的，顶点序列应满足\(<v_{i,j-1}, v_{i,j}> \in E\)，\(1 \le j \le m\)。树中根结点到任意结点的路径是唯一的，但是图中顶点与顶点之间的路径却是不唯一的。
  • 路径长度：路径上边或弧的数目/权值之和。例如，对于上图路径 (A,C,B,D)，其不带权路径长度为：3，带权路径长度为：12。
  • 回路或环：第一个顶点和最后一个顶点相同的路径称为回路或环。例如，上图 (A,C,B,A) 就是一个回路或环。
  • 简单路径：序列中顶点不重复出现的路径称为简单路径。例如，上图 (A,C,B,D) 就是一个简单路径。
  • 简单回路或简单环：除了第一个顶点和最后一个顶点之外，其余顶点不重复出现的回路，称为简单回路或简单环。例如，上图 (A,C,B,A) 就是一个简单回路或简单环。
  • 连通、连通图和连通分量：在无向图 \(G\) 中，如果从顶点 \(v\) 到顶点 \(v'\) 有路径，则称 \(v\) 和 \(v'\) 是连通的。 如果对于图中任意两个顶点 \(v_i、v_j \in V\)，\(v_i\) 和 \(v_j\) 都是连通的，则称 \(G\) 是连通图。无向图中的极大连通子图称为连通分量。所谓极大连通子图就是图中含有极大顶点数的一个连通子图，这个子图不能再加入任何一个顶点，否则就会导致子图不再连通。对于连通图，只有一个连通分量(即它自己)；而对于非连通图，一定有多个连通分量。
  • 强连通图和强连通分量：在有向图 \(G\) 中，如果对于每一对 \(v_i, v_j \in V,v_i \neq v_j\)，从 \(v_i\) 到 \(v_j\) 和从 \(v_j\) 到 \(v_i\) 都存在路径，则称 \(G\) 是强连通图。有向图中的极大强连通子图称作有向图的强连通分量。
  • 极小连通子图和生成树：所谓极小连通子图就是图中含有极小边数的一个连通子图，这个子图不能再删除任何一条边，否则就会导致子图不再连通。包含连通图 \(G\) 所有顶点的极小连通子图称为 \(G\) 的生成树。
    • 生成树是相对于连通图而言的，如果图都不连通，那么就无法生成一棵连通所有点的树。
    • 对于有 n 个结点的图，它的生成树只能有 n-1 条边。并且生成树还要连通所有的点，不能有环。
  • 有向树和生成森林：有一个顶点的入度为 0，其余顶点的入度均为 1 的有向图称为有向树。一个有向图的生成森林是由若干棵有向树组成，含有图中全部顶点，但只有足以构成若干棵不相交的有向树的弧。

图的存储结构

邻接矩阵

邻接矩阵（Adjacency Matrix）：是用两个数组来表示图。一个一维数组存储图中顶点信息，一个二维数组（称为邻接矩阵）存储图中的边或弧的信息。

设图 \(G\) 有 \(n\) 个顶点，则邻接矩阵是一个 \(n \times n\)的方阵，定义为：

$$ \text{arc}[i][j] = \begin{cases} 1, & \text{若 } (v_i, v_j) \in E \text{ 或 } \langle v_i, v_j \rangle \in E \\ 0, & \text{反之} \end{cases} $$

举个例子：

设网 \(G\) 有 \(n\) 个顶点，则邻接矩阵是一个 \(n \times n\)的方阵，定义为：

$$ \text{arc}[i][j] = \begin{cases} W_{ij}, & \text{若 } (v_i, v_j) \in E \text{ 或 } \langle v_i, v_j \rangle \in E \\ 0, & \text{若 } i = j \\ \infty, & \text{反之} \end{cases} $$

举个例子：

#define MaxInt 32767                     // 极大值∞
#define MVNum 100                        // 最大顶点数
typedef char VerTexType;                 // 顶点类型
typedef int ArcType;                     // 边的权值类型

typedef struct {
    VerTexType vexs[MVNum];              // 顶点表
    ArcType arcs[MVNum][MVNum];          // 邻接矩阵
    int vexnum, arcnum;                  // 当前点数和边数
} AMGraph;

邻接矩阵的优缺点：

优点：

  • 便于判断两个顶点之间是否有边，即根据A[i][j] = 0 或 1 来判断。
  • 便于计算各个顶点的度。对于无向图，邻接矩阵第 i 行元素之和就是顶点 i 的度；对于有向图，第 i 行元素之和就是顶点 i 的出度，第 i 列元素之和就是顶点 i 的入度。

缺点：

  • 不便于增加和删除顶点。
  • 不便于统计边的数目，需要扫描邻接矩阵所有元素才能统计完毕，时间复杂度为O(n²)。
  • 空间复杂度高。如果是有向图，n 个顶点需要 n 个单元存储边。如果是无向图，因其邻接矩阵是对称的，所以对规模较大的邻接矩阵可以采用压缩存储的方法，仅存储下三角（或上三角）的元素，这样需要 n(n-1)/2 个单元即可。但无论以何种方式存储，邻接矩阵表示法的空间复杂度均为O(n²)，这对于稀疏图而言尤其浪费空间。

现实中的图一般都是稀疏图，即边的数量 \(E\) 远小于顶点数量 \(V\) 的平方 \((E \ll V^2)\)，因此一般不使用邻接矩阵来表示图。但是由于邻接矩阵可以在 \(O(1)\) 时间内快速判断两个顶点之间是否有边以及边的权值，因此在图非常小、稠密图或者需要快速判断两点间是否有边的场景，邻接矩阵还是很有用的。

邻接表

邻接表（Adjacency List）：对图中每个顶点 \(v_i\) 建立一个单链表，把与 \(v_i\) 相邻接的顶点放在这个链表中。邻接表中每个单链表的第一个结点存放有关顶点的信息，把这一结点看成链表的表头，其余结点存放有关边的信息，这样邻接表便由两部分组成：表头结点表和边表。

  1. 表头结点表：由所有表头结点以顺序结构的形式存储，以便可以随机访问任一顶点的边链表。表头结点包括数据域（data）和链域（firstarc）两部分。其中，数据域用于存储顶点 \(v_i\) 的名称或其他有关信息；链域用于指向链表中第一个结点（即与顶点 \(v_i\) 邻接的第一个邻接点）。
  2. 边表：由表示图中顶点间关系的 \(2n\) 个边链表组成。边链表中边结点包括邻接点域（adjvex）、数据域（info）和链域（nextarc）三部分。其中，邻接点域指示与顶点 \(v_i\) 邻接的点在图中的位置；数据域存储和边相关的信息，如权值等；链域指示与顶点 \(v_i\) 邻接的下一条边的结点。

举个例子：

#define MVNum 100
typedef struct ArcNode {                 // 边结点
    int adjvex;
    struct ArcNode *nextarc;
    OtherInfo info;
} ArcNode;

typedef struct VNode {                   // 顶点信息
    VerTexType data;
    ArcNode *firstarc;
} VNode, AdjList[MVNum];

typedef struct {                         // 邻接表
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;

邻接表的优缺点：

优点：

  • 便于增加和删除顶点。
  • 便于统计边的数目，按顶点表顺序扫描所有边表可得到边的数目，时间复杂度为 \(O(n+e)\)。
  • 空间效率高。对于一个具有 \(n\) 个顶点 \(e\) 条边的图 \(G\)，若 \(G\) 是无向图，则在其邻接表表示中有 \(n\) 个顶点表结点和 \(2e\) 个边表结点；若 \(G\) 是有向图，则在它的邻接表表示或逆邻接表表示中均有 \(n\) 个顶点表结点和 \(e\) 个边表结点。因此，邻接表或逆邻接表表示的空间复杂度为 \(O(n+e)\)，适合表示稀疏图。对于稠密图，考虑到邻接表中要附加链域，因此常采取邻接矩阵表示法。

缺点：

  • 不便于判断顶点之间是否有边，要判定 \(v_i\) 和 \(v_j\) 之间是否有边，就需扫描第 \(i\) 个边表，最坏情况下要耗费 \(O(n)\) 时间。
  • 不便于计算有向图各个顶点的度。对于无向图，在邻接表表示中顶点 \(v_i\) 的度是第 \(i\) 个边表中的结点个数。在有向图的邻接表中，第 \(i\) 个边表上的结点个数是顶点 \(v_i\) 的出度，但求 \(v_i\) 的入度较困难，需遍历各顶点的边表。若有向图采用逆邻接表表示，则与邻接表表示相反，求顶点的入度容易，而求顶点的出度较难。

十字链表

对于有向图来说，使用邻接表求顶点的出度容易，但求顶点的入度难，必须遍历整个图才能确定。使用逆邻接表则相反，求顶点的入度容易，而求顶点的出度较难。因此，可以把邻接表与逆邻接表结合起来，这就是十字链表。

  1. 顶点结点，由 3 个域组成：其中 data 域存储和顶点相关的信息，如顶点的名称等；firstin 和 firstout 为两个链域，分别指向以该顶点为弧头或弧尾的第一个弧结点。
  2. 弧结点，由 5 个域组成：其中尾域（tailvex）和头域（headvex）分别指示弧尾和弧头这两个顶点在图中的位置，链域 hlink 指向弧头相同的下一条弧，而链域 tlink 指向弧尾相同的下一条弧，info 域指向该弧的相关信息。弧头相同的弧在同一链表上，弧尾相同的弧也在同一链表上。

举个例子：

#define MAX_VERTEX_NUM 20
typedef struct ArcBox {
    int tailvex, headvex;          //该弧的尾和头顶点的位置
    struct ArcBox *hlink, *tlink;  //分别为弧头相同和弧尾相同的弧的链域
    InfoType *info;                //该弧相关信息的指针
} ArcBox;

typedef struct VexNode {
    VertexType data;
    ArcBox *firstin, *firstout;    //分别指向该顶点第一条入弧和出弧
} VexNode;

typedef struct {
    VexNode xlist[MAX_VERTEX_NUM]; //表头向量
    int vexnum, arcnum;            //有向图的当前顶点数和弧数
} OLGraph;

邻接多重表

对于无向图来说，使用邻接表会出现每条边被重复存储两次的情况。这就导致要删除一条边时，需要找到这条边的两个边表结点进行操作，这是比较麻烦的。使用邻接多重表可以避免这个问题。

  1. 顶点结点，由 6 个域组成。其中，mark 为标志域，可用以标记该条边是否被搜索过；ivex 和 jvex 为该边依附的两个顶点在图中的位置；ilink 指向下一条依附于顶点 ivex 的边；jlink 指向下一条依附于顶点 jvex 的边，info 为指向和边相关的各种信息的指针域。
  2. 边结点，由 2 个域组成。其中，data 域存储和该顶点相关的信息，firstedge 域指示第一条依附于该顶点的边。

举个例子：

#define MAX_VERTEX_NUM  20
typedef enum{unvisited,visited} VisitIf;
typedef struct EBox {
    VisitIf mark;                  //访问标记
    int ivex, jvex;                //该边依附的两个顶点的位置
    struct EBox *ilink, *jlink;    //分别指向依附这两个顶点的下一条边
    InfoType *info;                //该边信息指针
} Ebox;

typedef struct VexBox {
    VertexType data;
    EBox *firstedge;               //指向第一条依附该顶点的边
} VexBox;

typedef struct{
    VexBox adjmulist[MAX_VERTEX_NUM];
    int vexnum, edgenum;           //无向图的当前顶点数和边数
} AMLGraph;

图的代码实现

由于邻接矩阵仅适用于图非常小、稠密图或者需要快速判断两点间是否有边的场景，而十字链表专为有向图优化，邻接多重表专为无向图优化，因此在图的四种常见存储结构中，邻接表是最常用的。以下是基于邻接表的图的代码实现：

创建

int LocateVex(ALGraph G, VerTexType u);

bool CreateGraph(ALGraph &G, VerTexType V[], int vnum, VerTexType VR[][3], int arnum) {
    if (vnum > MVNum) return false;
    G.vexnum = vnum;
    G.arcnum = arnum;

    // 初始化顶点
    for (int i = 0; i < G.vexnum; ++i) {
        G.vertices[i].data = V[i];
        G.vertices[i].firstarc = NULL;
    }

    // 构造弧（头插法）
    for (int k = 0; k < G.arcnum; ++k) {
        VerTexType v1 = VR[k][0];  // 弧尾顶点
        VerTexType v2 = VR[k][1];  // 弧头顶点
        OtherInfo info = VR[k][2]; // 弧附加信息
        int i = LocateVex(G, v1);
        int j = LocateVex(G, v2);
        if (i == -1 || j == -1) return false;

        // 生成边结点并插入v的边链表
        ArcNode *p = new ArcNode;
        p->adjvex = j;
        p->info = info;
        p->nextarc = G.vertices[i].firstarc;
        G.vertices[i].firstarc = p;

        // 【无向图专用】取消注释以添加反向弧<v2, v1>（无向图就是每条边都是两条相反方向的弧的有向图）
        /*
        ArcNode *q = new ArcNode;
        q->adjvex = i;
        q->info = info;
        q->nextarc = G.vertices[j].firstarc;
        G.vertices[j].firstarc = q;
        */
    }
    return true;
}

销毁

void DestroyGraph(ALGraph &G) {
    ArcNode *p, *q;
    for (int i = 0; i < G.vexnum; ++i) {
        p = G.vertices[i].firstarc;
        while (p) {
            q = p->nextarc;
            delete p;
            p = q;
        }
        G.vertices[i].firstarc = NULL;
    }
    G.vexnum = 0;
    G.arcnum = 0;
}

获取顶点在图中的位置

int LocateVex(ALGraph G, VerTexType u) {
    for (int i = 0; i < G.vexnum; ++i) {
        if (G.vertices[i].data == u) return i;
    }
    return -1;

bool DeleteVex(ALGraph &G, VerTexType v) {
    int pos = LocateVex(G, v);
    if (pos == -1) return false;

    // 1. 删除所有以该顶点为弧尾的边（出边），同时减少arcnum
    ArcNode *p = G.vertices[pos].firstarc;
    while (p) {
        ArcNode *q = p->nextarc;
        delete p;
        p = q;
        G.arcnum--;
    }
    G.vertices[pos].firstarc = NULL;

    // 2. 删除所有以该顶点为弧头的边（入边），同时减少arcnum
    for (int i = 0; i < G.vexnum; ++i) {
        if (i == pos) continue;
        ArcNode *prev = NULL;
        p = G.vertices[i].firstarc;
        while (p) {
            if (p->adjvex == pos) {
                if (prev) prev->nextarc = p->nextarc;
                else G.vertices[i].firstarc = p->nextarc;
                ArcNode *tmp = p;
                p = p->nextarc;
                delete tmp;
                G.arcnum--;
            } else {
                prev = p;
                p = p->nextarc;
            }
        }
    }

    // 3. 顶点数组前移（删除位置pos）
    for (int i = pos + 1; i < G.vexnum; ++i) {
        G.vertices[i - 1] = G.vertices[i];
    }
    G.vexnum--;

    // 4. 更新所有边结点中的adjvex值（大于pos的索引减1）
    for (int i = 0; i < G.vexnum; ++i) {
        p = G.vertices[i].firstarc;
        while (p) {
            if (p->adjvex > pos) p->adjvex--;
            p = p->nextarc;
        }
    }
    return true;
}

以上是图的深度优先遍历的示意图，其遍历顺序可能为：ABCDEFGHI。

以上是图的广度优先遍历的示意图，其遍历顺序可能为：A BF CDG EHI。

图的遍历算法的一般流程为：

  1. 定义点集 \(X\) 为已经处理的点，点集 \(F\) 为已发现但尚未处理的点
  2. 初始化点集 \(X\) 为空，点集 \(F\) 只包含搜索的起点
  3. 只要点集 \(F\) 不为空，循环步骤 4~6：
    1. 从点集 \(F\) 中取出一个点 \(v\)
    2. 处理点 \(v\)，把点 \(v\) 加入点集 \(X\)
    3. 遍历 \(v\) 的出边，对于每个 \(v\) 的邻居，若既不在点集 \(X\) 中也不在点集 \(F\) 中，则将其加入点集 \(F\)
  4. 搜索结束，点集 \(X\) 里的点是搜索过的点

以上流程最关键的就是步骤 4，也就是取出点 \(v\) 的方式，如果点集 \(F\) 是一个栈，那整个遍历过程就是深度优先遍历。如果点集 \(F\) 是一个队列，那整个遍历过程就是广度优先遍历。

深度优先遍历 (DFS)

深度优先遍历除了一般流程外，还可以通过递归实现。

递归实现的流程为：

  1. 定义点集 \(X\) 为已经处理的点，点集 \(F\) 为已发现但尚未处理的点
  2. 初始化点集 \(X\) 为空，点集 \(F\) 只包含搜索的起点
  3. 递归搜索点 \(v\) (开始时搜索起点)：
    1. 从点集 \(F\) 中取出一个点 \(v\)
    2. 处理点 \(v\)，把点 \(v\) 加入点集 \(X\)
    3. 遍历 \(v\) 的出边，对于每个 \(v\) 的邻居，若既不在点集 \(X\) 中也不在点集 \(F\) 中，则递归处理那个点
  4. 搜索结束，点集 \(X\) 里的点是搜索过的点

其中，用栈实现和用递归实现的DFS会有小的差别：

对于以上实例，

  • 如果用栈实现，其遍历顺序不可能是：1234。因为 3 会被 1 先发现，3 不会被 2 先发现。
  • 如果用递归实现，其遍历顺序有可能是：1234。

图的应用

最小生成树

最小生成树（Minimum Spanning Tree，MST）：给定一个无向网，在该网的所有生成树中，使得各边的权值之和最小的那棵生成树称为该网的最小生成树。

Prim（普里姆）算法

Prim（普里姆）算法是一种加点法，适用于稠密图。

假设 \(N = (V, E)\)是一个无向网，\(U\) 是最小生成树的顶点集，\(TE\) 是最小生成树的边集，起初 \(U = \{\},TE = \{\}\)。假设 \(u_0(u_0 \in V)\) 是选中的第一个顶点。那么构建最小生成树的流程为：

  1. \(U = \{u_0\},TE = \{\}\)。
  2. 在所有 \(u \in U, v \in V - U\) 的边 \((u,v)\) 中，选择权值最小的边 \(u_0,v_0\) 加入集合 \(TE\)，同时把 \(v_0\) 加入集合 \(U\)。
    3. V-U 是剩余顶点集
  3. 重复步骤 2，直到 \(U = V\) 为止。

此时 \(TE\) 中必有 \(n-1\) 条边，\(U = V\)，则 \(T = (U,TE)\) 就是最小生成树。

// 辅助函数：获取 v 到 w 的权值
OtherInfo GetWeight(ALGraph G, int v, int w) {
    ArcNode *p = G.vertices[v].firstarc;
    while (p) {
        if (p->adjvex == w) return p->info;
        p = p->nextarc;
    }
    return INFINITY; // 无边则返回无穷大
}

bool Prim(ALGraph G, VerTexType start_vertex) {
    int start = LocateVex(G, start_vertex);
    if (start == -1) return false;

    // 辅助数组
    int lowcost[MVNum];  // lowcost[j]：未选顶点j到已选集的最小权值
    int adjvex[MVNum];   // adjvex[j]：lowcost[j]对应的已选顶点下标
    bool selected[MVNum];// selected[j]：顶点j是否已选

    // 1. 初始化辅助数组
    for (int j = 0; j < G.vexnum; ++j) {
        lowcost[j] = GetWeight(G, start, j); // 初始为起点到各顶点的权值
        adjvex[j] = start;                     // 初始最小权值对应的已选顶点为起点
        selected[j] = false;                   // 所有顶点未选
    }
    selected[start] = true; // 起点加入已选集
    int total_weight = 0;   // 最小生成树总权值

    // 2. 循环n-1次，选n-1条边
    for (int i = 1; i < G.vexnum; ++i) {
        // 步骤1：找lowcost中最小的未选顶点k
        int min_weight = INFINITY;
        int k = -1;
        for (int j = 0; j < G.vexnum; ++j) {
            if (!selected[j] && lowcost[j] < min_weight) {
                min_weight = lowcost[j];
                k = j;
            }
        }

        if (k == -1) {
            printf("图不连通，无法生成最小生成树！\n");
            return false;
        }

        // 步骤2：将k加入已选集，输出边(adjvex[k], k)
        selected[k] = true;
        printf("%c --(%d)-- %c\n", 
               G.vertices[adjvex[k]].data, 
               min_weight, 
               G.vertices[k].data);
		total_weight += min_weight;

        // 步骤3：更新lowcost和adjvex（因为k加入了已选集）
        for (int j = 0; j < G.vexnum; ++j) {
            if (!selected[j]) {
                OtherInfo weight = GetWeight(G, k, j);
                if (weight < lowcost[j]) {
                    lowcost[j] = weight;  // 更新为更小的权值
                    adjvex[j] = k;         // 更新对应的已选顶点为k
                }
            }
        }
    }

    printf("最小生成树总权值：%d\n", total_weight);
    return true;
}

Kruskal（克鲁斯卡尔）算法

Kruskal（克鲁斯卡尔）算法是一种加边法，适用于稀疏图。

假设连通网 \(N = (V, E)\)，则将 \(N\) 中的边按权值从小到大的顺序排列。

  1. 初始状态为只有 \(n\) 个顶点而无边的非连通图 \(T = (V, {})\)，图中每个顶点自成一个连通分量。
  2. 在 \(E\) 中选择权值最小的边，若该边依附的顶点落在 \(T\) 中不同的连通分量上（即不形成回路），则将此边加入到 \(T\) 中，否则舍去此边而选择下一条权值最小的边。
  3. 重复步骤 2，直至 \(T\) 中所有顶点都在同一连通分量上为止。
// Kruskal专用：边结构体
typedef struct {
    int start;    // 边的起点下标
    int end;      // 边的终点下标
    int weight;   // 边的权值
} Edge;

// Initial 初始化并查集
void Initial(int p[], int n) {
    for(int i = 0; i < n; i++) {
        p[i] = -1;
    }
}

// Find 并查集查找操作
int Find(int p[], int x) {
    if(p[x] < 0)
        return x;
    else
        return p[x] = Find(p, p[x]);
}
 
// Union 并查集合并操作（秩为树的高度）
void Union(int p[], int x, int y) {
    int rootx = Find(p, x);
    int rooty = Find(p, y);
    if(rootx != rooty) {
        if(p[rootx] < p[rooty]) {
            p[rooty] = rootx;
        } else if(p[rootx] > p[rooty]) {
            p[rootx] = rooty;
        } else {
            p[rootx] = rooty;
            p[rooty]--;
        }
    }
}

// ExtractEdges 从邻接表提取边数组（避免重复）
int ExtractEdges(ALGraph G, Edge edges[]) {
    int edgeCount = 0;
    for (int i = 0; i < G.vexnum; ++i) {
        ArcNode *p = G.vertices[i].firstarc;
        while (p) {
            // 关键：只处理i < p->adjvex的边，避免无向图中边的重复存储
            if (i < p->adjvex) {
                edges[edgeCount].start = i;
                edges[edgeCount].end = p->adjvex;
                edges[edgeCount].weight = p->info;
                edgeCount++;
            }
            p = p->nextarc;
        }
    }
    return edgeCount;
}

// CompareEdges 用于 qsort 的比较函数，边数组按权值排序（升序）
int CompareEdges(const void *a, const void *b) {
    Edge *edgeA = (Edge *)a;
    Edge *edgeB = (Edge *)b;
    return edgeA->weight - edgeB->weight; // 升序：返回负数则a在前
}

// Kruskal（克鲁斯卡尔）算法
bool Kruskal(ALGraph G) {
    Edge edges[MVNum * MVNum]; // 边数组（最多MVNum*(MVNum-1)/2条边）
    int edgeCount = ExtractEdges(G, edges); // 从邻接表提取所有边

    // 步骤1：按权值升序排序所有边
    qsort(edges, edgeCount, sizeof(Edge), CompareEdges);

    // 步骤2：初始化并查集
    int p[MVNum]; // 父节点数组
    Initial(p, G.vexnum);

    int selectedEdges = 0; // 已选边数（需选n-1条）
    int totalWeight = 0;   // 最小生成树总权值

    // 步骤3：遍历排序后的边，选n-1条不形成环的边
    for (int i = 0; i < edgeCount && selectedEdges < G.vexnum - 1; ++i) {
        int u = edges[i].start;
        int v = edges[i].end;
        int rootU = Find(p, u);
        int rootV = Find(p, v);

        if (rootU != rootV) { // 两个顶点不在同一集合，选这条边
            Union(p, rootU, rootV); // 合并集合
            // 输出边（起点和终点的顶点值）
            printf("%c --(%d)-- %c\n", 
                   G.vertices[u].data, 
                   edges[i].weight, 
                   G.vertices[v].data);
            totalWeight += edges[i].weight;
            selectedEdges++;
        }
    }

    // 检查图是否连通
    if (selectedEdges < G.vexnum - 1) {
        printf("图不连通，无法生成最小生成树！\n");
        return false;
    }

    printf("最小生成树总权值：%d\n", totalWeight);
    return true;
}

Dijkstra（迪杰斯特拉）算法：是用来求图中一个点到其他所有点的最短路径的算法。

假设用带权的邻接表来表示带权有向网 \(N\)，其中顶点 \(v_i\) 的邻接表中存储所有以 \(v_i\) 为起点的弧，每个表项包含邻接顶点 \(v_j\) 和弧 \(<v_i, v_j>\) 上的权值。若 \(<v_i, v_j>\) 不存在，则顶点 \(v_i\) 的邻接表中权值为 \(\infty\)，源点为 \(v_0\)。

算法的实现要引入以下辅助的数据结构：

  1. 一维数组 S[MVNum]：记录从源点 \(v_0\) 到终点 \(v_i\) 是否已被确定最短路径长度，true 表示确定，false 表示尚未确定。
  2. 一维数组 Path[MVNum]：记录从源点 \(v_0\) 到终点 \(v_i\) 的当前最短路径上 \(v_i\) 的直接前驱顶点序号。其初值为：如果从 \(v_0\) 到 \(v_i\) 有弧，则 Path[i] 为 \(v_0\)；否则为 -1。
  3. 一维数组 D[MVNum]：记录从源点 \(v_0\) 到终点 \(v_i\) 的当前最短路径长度。其初值为：如果从 \(v_0\) 到 \(v_i\) 有弧，则 D[i] 为弧上的权值；否则为 \(\infty\)。

显然，长度最短的一条最短路径必为 (v_0, v_k)，满足以下条件：

$$ D[k] = Min\{D[i] | v_i ∈ V - S\} $$

求得顶点 \(v_k\) 的最短路径后，将其加入到第一组顶点集 \(S\) 中。

每当加入一个新的顶点到顶点集 \(S\)，对第二组剩余的各个顶点而言，多了一个“中转”顶点，从而多了一个“中转”路径，所以要对第二组剩余的各个顶点的最短路径长度进行更新。

原来 \(v_0\) 到 \(v_i\) 的最短路径长度为 \(D[i]\)，加进 \(v_k\) 之后，需遍历 \(v_k\) 的邻接表，对每个邻接顶点 \(v_i\) 及其对应的弧权值 \(weight\)，考虑以 \(v_k\) 作为中间顶点的“中转”路径长度：\(D[k] + weight\)。若 \(D[k] + weight < D[i]\)，则用 \(D[k] + weight\) 取代 \(D[i]\)，并更新 \(Path[i]\) 为 \(v_k\)。

更新后，再选择数组 \(D\) 中值最小的顶点加入到第一组顶点集 \(S\) 中，如此进行下去，直到图中所有顶点都加入到第一组顶点集 \(S\) 中为止。

bool Dijkstra(ALGraph G, VerTexType start) {
    int s = LocateVex(G, start);
    if (s == -1) return false;

    int dist[MVNum];     // 源点到i的最短距离
    int visited[MVNum];  // 是否已确定最短路径
    int path[MVNum];     // 前驱结点，记录路径

    // 初始化
    for (int i = 0; i < G.vexnum; ++i) {
        dist[i] = GetWeight(G, s, i);
        visited[i] = 0;
        path[i] = (dist[i] < INFINITY) ? s : -1;
    }
    visited[s] = 1;
    dist[s] = 0;

    // 循环 n-1 次
    for (int i = 1; i < G.vexnum; ++i) {
        // 1. 选未访问中 dist 最小的 u
        int min = INFINITY;
        int u = -1;
        for (int j = 0; j < G.vexnum; ++j) {
            if (!visited[j] && dist[j] < min) {
                min = dist[j];
                u = j;
            }
        }
        if (u == -1) break; // 剩余点不可达
        visited[u] = 1;

        // 2. 松弛更新
        for (int v = 0; v < G.vexnum; ++v) {
            if (!visited[v]) {
                int w = GetWeight(G, u, v);
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    path[v] = u;
                }
            }
        }
    }

    // 输出结果
    for (int i = 0; i < G.vexnum; ++i) {
        if (i == s) continue;
        printf("%c -> %c  最短距离：", G.vertices[s].data, G.vertices[i].data);
        if (dist[i] >= INFINITY)
            printf("不可达\n");
        else
            printf("%d\n", dist[i]);
    }
    return true;
}

Floyd（弗洛伊德）算法：是用来求图中任意两个顶点对之间的最短路径的算法。

假设使用带权的邻接矩阵 \(arcs\) 来表示有向网 \(N\)，求从顶点 \(v_i\) 到 \(v_j\) 的最短路径。

算法的实现要引入以下辅助的数据结构：

  1. 二维数组 \(Path[i][j]\)：最短路径上顶点 \(v_j\) 的前一顶点的序号。
  2. 二维数组 \(D[i][j]\)：记录顶点 \(v_i\) 和 \(v_j\) 之间的最短路径长度。

将 \(v_i\) 到 \(v_j\) 的最短路径长度初始化，即 \(D[i][j] = G.arcs[i][j]\)，然后进行 \(n\) 次比较和更新。

  1. 在 \(v_i\) 和 \(v_j\) 间加入顶点 \(v_0\)，比较 \((v_i, v_j) 和 (v_i, v_0, v_j)\) 的路径长度，取其中较短者作为 \(v_i\) 到 \(v_j\) 的中间顶点序号不大于 0 的最短路径。
  2. 在 \(v_i\) 和 \(v_j\) 间加入顶点 \(v_1\)，得到 \((v_i, …, v_1) 和 (v_1, …, v_j)\)，其中 \((v_i, …, v_1)\) 是 \(v_i\) 到 \(v_1\) 的且中间顶点的序号不大于 0 的最短路径，\((v_1, …, v_j)\) 是 \(v_1\) 到 \(v_j\) 的且中间顶点的序号不大于 0 的最短路径，这两条路径已在上一步中求出。比较 \((v_i, …, v_1, …, v_j)\) 与上一步求出的 \(v_i\) 到 \(v_j\) 的中间顶点序号不大于 0 的最短路径，取其中较短者作为 \(v_i\) 到 \(v_j\) 的中间顶点序号不大于 1 的最短路径。
  3. 依次类推，在 \(v_i\) 和 \(v_j\) 间加入顶点 \(v_k\)，若 \((v_i, …, v_k)\) 和 \((v_k, …, v_j)\) 分别是从 \(v_i\) 到 \(v_k\) 和从 \(v_k\) 到 \(v_j\) 的中间顶点的序号不大于 \(k-1\) 的最短路径，则将 \((v_i, …, v_k, …, v_j)\) 和已经得到的从 \(v_i\) 到 \(v_j\) 且中间顶点序号不大于 \(k-1\) 的最短路径相比较，其长度较短者便是从 \(v_i\) 到 \(v_j\) 的中间顶点的序号不大于 \(k\) 的最短路径。这样，经过 \(n\) 次比较后，最后求得的必是从 \(v_i\) 到 \(v_j\) 的最短路径。按此方法，可以同时求得各对顶点间的最短路径。

根据上述求解过程，图中的所有顶点对 \(v_i\) 和 \(v_j\) 间的最短路径长度对应一个 \(n\) 阶方阵 \(D\)。在上述 \(n+1\) 步中，\(D\) 的值不断变化，对应一个 \(n\) 阶方阵序列。

\(n\) 阶方阵序列可定义为：

$$ D^{(-1)}, D^{(0)}, D^{(1)}, …, D^{(k)}, …, D^{(n-1)} $$

其中，

$$ D^{(-1)}[i][j] = G.arcs[i][j] D^{(k)}[i][j] = Min{D^{(k-1)}[i][j], D^{(k-1)}[i][k] + D^{(k-1)}[k][j]}, 0 ≤ k ≤ n-1 $$

显然，\(D^{(1)}[i][j]\) 是从 \(v_i\) 到 \(v_j\) 的中间顶点的序号不大于 1 的最短路径的长度；\(D^{(k)}[i][j]\) 是从 \(v_i\) 到 \(v_j\) 的中间顶点的序号不大于 \(k\) 的最短路径的长度；\(D^{(n-1)}[i][j]\) 就是从 \(v_i\) 到 \(v_j\) 的最短路径的长度。

// PrintPath 辅助函数，递归回溯打印路径：从顶点i到顶点j
void PrintPath(MGraph G, int path[MVNum][MVNum], int i, int j) {
    if (i == j) {
        printf("%c", G.vexs[i]);
        return;
    }
    if (path[i][j] == -1) {
        printf("无路径");
        return;
    }
    PrintPath(G, path, i, path[i][j]);
    printf(" -> %c", G.vexs[j]);
}

// Floyd（弗洛伊德）算法（邻接矩阵实现）
bool Floyd(MGraph G) {
    int dist[MVNum][MVNum];  // dist[i][j]：顶点i到j的最短距离
    int path[MVNum][MVNum];  // path[i][j]：i到j最短路径上j的前驱顶点

    // 1. 初始化距离矩阵和路径矩阵
    for (int i = 0; i < G.vexnum; ++i) {
        for (int j = 0; j < G.vexnum; ++j) {
            dist[i][j] = G.arcs[i][j];  // 直接复制邻接矩阵
            if (i != j && dist[i][j] < INFINITY)
                path[i][j] = i;  // 有直接边时，j的前驱是i
            else
                path[i][j] = -1; // 无直接边时，前驱为-1
        }
    }

    // 2. 核心三重循环：k为中间顶点
    // ⚠️ 注意：循环顺序必须是 k -> i -> j，k必须在最外层
    for (int k = 0; k < G.vexnum; ++k) {
        for (int i = 0; i < G.vexnum; ++i) {
            for (int j = 0; j < G.vexnum; ++j) {
                // 如果经过k的路径比当前路径更短，则更新
                if (dist[i][k] + dist[k][j] < dist[i][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                    path[i][j] = path[k][j];  // 更新j的前驱为k到j的前驱
                }
            }
        }
    }

    // 3. 输出所有顶点对的最短路径
    for (int i = 0; i < G.vexnum; ++i) {
        for (int j = 0; j < G.vexnum; ++j) {
            if (i == j) continue;  // 跳过自身到自身的路径
            printf("%c -> %c  最短距离：", G.vexs[i], G.vexs[j]);
            
            if (dist[i][j] >= INFINITY) {
                printf("不可达\n");
            } else {
                printf("%d  路径：", dist[i][j]);
                PrintPath(G, path, i, j);
                printf("\n");
            }
        }
        printf("\n");  // 每个起点的结果空一行分隔
    }

    return true;
}

拓扑排序

有向无环图：一个无环的有向图称作有向无环图（Directed AcyclineGraph），简称DAG图。

AOV-网：用顶点表示活动，用弧表示活动间的优先关系的有向图称为顶点表示活动的网（Activity On Vertex - Network），简称AOV-网。

拓扑排序：就是将图中所有点按照先后顺序排成序列。拓扑排序的充分必要条件是给定的有向图必须是一个有向无环图（DAG）。

拓扑排序的常用算法有Kahn算法（基于入度）和DFS算法（基于后序遍历）。

Kahn算法：每次选入度为 0 的点，然后删除这个点和它的出边。

bool TopologicalSort(ALGraph G) {
    int inDegree[MVNum] = {0}; // 入度数组，初始化为0
    int stack[MVNum];           // 用数组模拟栈（也可用队列，结果顺序不同但都合法）
    int top = -1;               // 栈顶指针，-1表示空栈

    // 1. 计算所有顶点的入度
    for (int i = 0; i < G.vexnum; ++i) {
        ArcNode *p = G.vertices[i].firstarc;
        while (p) {
            inDegree[p->adjvex]++;
            p = p->nextarc;
        }
    }

    // 2. 将所有初始入度为0的顶点入栈
    for (int i = 0; i < G.vexnum; ++i) {
        if (inDegree[i] == 0) {
            stack[++top] = i;
        }
    }

    // 3. 拓扑排序核心过程
    int count = 0; // 记录已输出的顶点数
    while (top != -1) {
        int v = stack[top--]; // 出栈
        printf("%c ", G.vertices[v].data);
        count++;

        // 遍历v的所有邻接点，入度减1
        ArcNode *p = G.vertices[v].firstarc;
        while (p) {
            int w = p->adjvex;
            inDegree[w]--;
            if (inDegree[w] == 0) {
                stack[++top] = w;
            }
            p = p->nextarc;
        }
    }
    printf("\n");

    // 4. 检查图是否有环（虽然题目说是DAG，但保留健壮性检查）
    if (count < G.vexnum) {
        printf("图中存在环，不是有向无环图（DAG）！\n");
        return false;
    }

    return true;
}

AOE-网和关键路径

AOE-网：用弧表示活动，用顶点表示事件（中间状态）有向图称为弧表示活动的网（Activity On Edge - Network），简称AOE-网。AOE-网也必须是有向无环图（DAG）。

AOE网通常用来表示工程活动的计划，每个弧表示一个活动，每个顶点表示一个事件（中间状态），弧的权重表示活动的持续时间等。例如，上图可以表示一个工程活动的计划，其中 A 是开始事件，F 是结束事件。

  • 关键路径：完成整个工程至少需要花费的时间取决于哪条路径最耗时，最耗时的这条路径就是关键路径。
  • 关键活动：关键路径上的活动就是关键活动。关键活动是不能拖延的活动，否则会导致整个工程的拖延。关键活动的最早开始时间 = 最晚开始时间。而其他活动是可以等的。

为了确定关键路径，首先定义 4 个描述量。

  1. ve：事件的最早开始时间。
  2. vl：事件的最晚开始时间。
  3. e：活动的最早开始时间。
  4. l：活动的最晚开始时间。

求关键路径的思路是：先通过拓扑排序求顶点的最早开始时间 ve ，再通过逆拓扑排序求顶点的最晚开始时间 vl，根据顶点的 ve 和 vl 求活动的最早开始时间 e 和最晚开始时间 l。最后，e = l 的活动就是关键活动，所有关键活动的路径就是关键路径。

  • 该边是哪个顶点的出边，该边的 e = 该顶点的 ve。
  • 该边是哪个顶点的入边，该边的 l = 该顶点的 vl - 该边的权重。

// TopologicalSort 拓扑排序（同时计算ve并保存拓扑序列）
bool TopologicalSort(ALGraph G, int topoOrder[], int ve[]) {
    int inDegree[MVNum] = {0};
    int stack[MVNum];
    int top = -1;
    int count = 0;

    // 初始化ve为0
    for (int i = 0; i < G.vexnum; ++i) {
        ve[i] = 0;
    }

    // 计算入度
    for (int i = 0; i < G.vexnum; ++i) {
        ArcNode *p = G.vertices[i].firstarc;
        while (p) {
            inDegree[p->adjvex]++;
            p = p->nextarc;
        }
    }

    // 入度为0入栈
    for (int i = 0; i < G.vexnum; ++i) {
        if (inDegree[i] == 0) {
            stack[++top] = i;
        }
    }

    // 拓扑排序核心
    while (top != -1) {
        int v = stack[top--];
        topoOrder[count++] = v; // 保存拓扑序列

        ArcNode *p = G.vertices[v].firstarc;
        while (p) {
            int w = p->adjvex;
            inDegree[w]--;
            // 计算ve：取最大值
            if (ve[v] + p->info > ve[w]) {
                ve[w] = ve[v] + p->info;
            }
            if (inDegree[w] == 0) {
                stack[++top] = w;
            }
            p = p->nextarc;
        }
    }

    if (count < G.vexnum) {
        printf("图中存在环，不是有向无环图（DAG）！\n");
        return false;
    }
    return true;
}

// ReverseTopologicalSort 逆拓扑排序（计算vl）
void ReverseTopologicalSort(ALGraph G, int topoOrder[], int ve[], int vl[]) {
    // 初始化vl为汇点的ve值
    int sink = topoOrder[G.vexnum - 1];
    for (int i = 0; i < G.vexnum; ++i) {
        vl[i] = ve[sink];
    }

    // 按拓扑序列的逆序计算vl
    for (int i = G.vexnum - 2; i >= 0; --i) {
        int v = topoOrder[i];
        ArcNode *p = G.vertices[v].firstarc;
        while (p) {
            int w = p->adjvex;
            // 计算vl：取最小值
            if (vl[w] - p->info < vl[v]) {
                vl[v] = vl[w] - p->info;
            }
            p = p->nextarc;
        }
    }
}

// CriticalPath 关键路径求解
bool CriticalPath(ALGraph G) {
    int ve[MVNum];       // 顶点最早发生时间
    int vl[MVNum];       // 顶点最迟发生时间
    int topoOrder[MVNum]; // 拓扑序列

    // 步骤1：拓扑排序求ve
    if (!TopologicalSort(G, topoOrder, ve)) {
        return false;
    }

    // 步骤2：逆拓扑排序求vl
    ReverseTopologicalSort(G, topoOrder, ve, vl);

    // 步骤3：遍历所有边，判定关键活动
    int totalDuration = ve[topoOrder[G.vexnum - 1]];
    for (int v = 0; v < G.vexnum; ++v) {
        ArcNode *p = G.vertices[v].firstarc;
        while (p) {
            int w = p->adjvex;
            int e = ve[v];       // 活动最早开始时间
            int l = vl[w] - p->info; // 活动最迟开始时间
            if (e == l) {
                printf("%c -> %c  %d\n", G.vertices[v].data, G.vertices[w].data, p->info);
            }
            p = p->nextarc;
        }
    }
    printf("工程最短完成时间：%d\n", totalDuration);
    return true;
}
