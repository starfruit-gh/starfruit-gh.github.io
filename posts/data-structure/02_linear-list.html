（二）线性表

线性表的定义

线性表：由 n(n≥0) 个相同数据类型的数据元素构成的有限序列。其中 n 为表长，n=0 时称为空表。

线性表的特点

  • 有限：线性表的元素个数必须是有限的。事实上，计算机处理的对象都是有限的，那种无限的序列，只存在于数学的概念中。
  • 有序：不同于数字0-9或者字符a-z这种由元素本身属性值决定的属性有序，线性表的有序是一种基于元素插入的先后顺序的逻辑上的位置有序——线性表存在唯一一个被称作“第一个”的数据元素，又称表头元素；存在唯一一个被称作“最后一个”的数据元素，又称表尾元素。除第一个元素外，每个元素均有且仅有一个直接前驱；除最后一个元素外，每个元素均有且仅有一个直接后继。
  • 类型相同：线性表的元素必须具有相同的数据类型。就像排队买票的队列里，所有成员都是需要购票的人，书包、雨伞等物品本质上不属于这个队列的合格成员，售票员不可能把票卖给书包、雨伞等物品。

线性表的顺序存储结构

顺序表的定义

用一段地址连续的存储单元依次存储线性表中的数据元素，从而使逻辑上相邻的元素在存储地址上也相邻。这种存储结构称为线性表的顺序存储结构，采用顺序存储结构的线性表通常称为顺序表。

顺序表的随机存取

顺序表在内存中占用连续的存储空间，且每个元素占用相同大小的存储空间。假设顺序表的基地址（第一个元素的存储地址）为 LOC(a₁)，每个元素占用的存储空间为 sizeof(ElemType)，则：

  • 相邻元素的存储关系：LOC(aᵢ₊₁) = LOC(aᵢ) + sizeof(ElemType)
  • 第 i 个元素的存储地址为：LOC(aᵢ) = LOC(a₁) + (i-1) × sizeof(ElemType)

因此，顺序表中的任意一个元素的存储地址都能在 O(1) 时间内通过基地址和序号 i 直接计算得出，而无需经过其他元素。这种基于地址计算的直接访问特性，使得顺序表成为一种支持随机存取的数据结构。

顺序表的代码实现

定义

typedef struct {
    // 1. 一个用来存储顺序表元素的一维数组
    ElemType *elem;
    // 2. 一个用来表示顺序表当前长度的整型变量
    int length;
} SeqList;

    L.elem = new ElemType[LIST_INIT_SIZE];
    // 2. 判断顺序表的数组指针是否为空，为空则空间分配失败，直接退出
    // if (!L.elem) exit(OVERFLOW);  // C++ 中无需判断
    // 3. 将顺序表的当前长度置为 0
    L.length = 0;
    return OK;
}

销毁

// DestroyList 销毁顺序表
void DestroyList(SeqList &L) {
    // 1. 判断顺序表的数组指针是否为空，为空则没有需要销毁的空间，直接返回
    if (L.elem) {
        // 2. 释放顺序表的数组占用的内存空间
        delete[] L.elem;
        // 3. 将顺序表的数组指针置为 NULL
        L.elem = NULL;
        // 4. 将顺序表的长度置为 0
        L.length = 0;
    }
}

// LocateElem 按值查找元素
int LocateElem(SeqList L, ElemType e) {
    // 1. 遍历顺序表
    for (int i = 0; i < L.length; i++) {
        // 2. 判断当前元素的值是否等于目标值
        if (L.elem[i] == e) 
            // 3. 如果有等于目标值的元素，则返回其下标
            return i + 1;
    }
    // 4. 如果没有等于目标值的元素，则返回 0
    return 0;
}

// LocateElem 按值查找元素（自定义比较函数）
int LocateElem(SeqList L, ElemType e, bool (*compare)(ElemType, ElemType)) {
    for (int i = 0; i < L.length; i++) {
        if (compare(L.elem[i], e)) 
            return i + 1;
    }
    return 0;
}

取值

// GetElem 按位查找
Status GetElem(SeqList L, int i, ElemType &e) {
    // 1. 判断要查找的位置 i 是否合法，如果不合法则返回 ERROR
    if (i < 1 || i > L.length) return ERROR;
    // 2. 如果位置合法，则将第 i 个元素的值赋给 e
    e = L.elem[i - 1];
    return OK;
}

插入

// ListInsert 在顺序表的第 i 个位置插入新元素 e
Status ListInsert(SeqList &L, int i, ElemType e) {
    // 1. 检查插入位置是否合法，如果不合法则返回 ERROR
    if (i < 1 || i > L.length + 1) return ERROR;
    // 2. 检查顺序表是否已满，如果已满则返回 ERROR
    if (L.length >= LIST_INIT_SIZE) return ERROR;
    // 3. 将第 i 个位置及之后的元素依次后移一位
    for (int j = L.length-1; j >= i-1; j--) {
        L.elem[j + 1] = L.elem[j];
    }
    // 4. 将新元素放入第 i 个位置
    L.elem[i - 1] = e;
    // 5. 表长加 1
    L.length++;
    return OK;
}

删除

// ListDelete 删除顺序表的第 i 个元素，并用 e 返回其值
Status ListDelete(SeqList &L, int i, ElemType &e) {
    // 1. 检查删除位置是否合法，如果不合法则返回 ERROR
    if (i < 1 || i > L.length) return ERROR;
    // 2. 将第 i 个元素的值保存到 e 中
    e = L.elem[i - 1];
    // 3. 将第 i+1 个元素及其后的所有元素依次前移一位
    for (int j = i; j <= L.length-1; j++) {
        L.elem[j - 1] = L.elem[j];
    }
    // 4. 表长减 1
    L.length--;
    return OK;
}

遍历

// ListTraverse 遍历顺序表并打印每个元素
void ListTraverse(SeqList L) {
    // 1. 遍历顺序表
    for (int i = 0; i < L.length; i++) {
        // 2. 打印当前元素
        printf("%c ", L.elem[i]);
    }
    // 换行
    printf("\n");
}

// ListTraverse 遍历顺序表（自定义访问函数）
void ListTraverse(SeqList L, void (*visit)(ElemType)) {
    for (int i = 0; i < L.length; i++) {
        visit(L.elem[i]);
    }
}

线性表的链式存储结构

链表的定义

用一组任意地址的存储单元存储线性表中的数据元素。为表示每个数据元素之间的逻辑关系，每个数据元素（又称结点）除存储本身的数据外，还要存储一个或多个指针，通过这些指针来指示其前驱和/或后继元素的位置。这种存储结构称为线性表的链式存储结构，采用链式存储结构的线性表通常称为链表。

  • 结点：线性表链式存储结构中的每个数据元素，由数据域和指针域两部分组成。
  • 数据域：结点中用于存储元素数据的部分。
  • 指针域：结点中用于存放指向其他结点地址的指针的部分，用来维护元素间的逻辑关系。
  • 链表：由一系列结点通过指针依次连接而成的线性结构。
  • 头指针：指向链表中第一个结点的指针，是访问链表的入口。
  • 首元结点：链表中第一个存储有效数据的结点。
  • 头结点：为了操作方便，在首元结点之前附加的一个结点，其数据域通常不存储实际数据，头结点的指针域指向首元结点。

在链表中设置头结点有什么好处？

1. 统一操作逻辑

如果不使用头结点，链表的插入、删除操作会存在表头和其他位置操作不一致的情况。如果在表头进行插入/删除操作，除了要新增或者删除结点以外，还要让头指针指向新的首元结点，而其他位置则不需要动头指针，因此每次操作需要先判断操作的位置是不是表头来分情况处理。

另外，通过尾插法来建立链表的操作也会存在插入链表的第一个结点和后续结点操作不同的情况。

而如果使用头结点的话，链表的插入、删除以及通过尾插法来建立链表的操作就都可以进行统一处理，不需要先判断然后再分情况处理了。

对于链表的头插法，由于头插法在不使用头结点的情况下本来就是统一操作，使用头结点只是让头指针不再随插入元素而变动，而是固定指向头结点。

而对于链表的初始化、销毁、清空、判空、求表长、查找、取值这些操作，相比于插入、删除以及通过尾插法来建立链表的操作来说，有无头结点差异不大。

2. 简化边界处理

如果不使用头结点，那么在对链表进行操作时，就可能需要先判断链表是否为空，以免直接解引用空指针（如 L->next 或 L->data）造成程序崩溃。

有头结点时，由于头指针永远不为 NULL（始终指向有效的头结点），因此对链表的操作避免了因头指针为 NULL 导致的空指针异常。

3. 保持头指针的稳定性

有头结点的链表，头指针始终指向固定的头结点，不会因任何插入、删除数据结点的操作而变动，这降低了 "链表入口丢失" 的风险，即使函数参数没有使用引用，只要能访问到头指针，就能找到整个链表。

4. 简化算法的实现

在处理合并、逆序、排序等复杂链表算法时，头结点可以作为一个固定的 "哨兵结点"，提供一个稳定的起点，避免频繁修改头指针，让算法逻辑更简洁、更不易出错。例如：合并两个有序链表时，直接创建一个结果链表的头结点，所有结点的插入逻辑完全统一，无需单独处理结果链表为空的情况。

链表的顺序存取

对于单链表，任意一个未知结点的地址只有通过其前驱结点才能获得，而前驱结点的地址只有通过该前驱结点的前驱结点才能获得，逻辑上需要一直追溯到某个已知地址的结点，才能从这个已知结点出发，依次遍历后继结点，最终逐步找到目标结点的地址。而这个已知地址的结点通常只有头指针指向的头结点。

双向链表同理，任意一个未知结点的地址只有通过其前驱或后继结点才能获得，即使双向链表支持双向遍历，但仍然无法直接计算出任意未知结点的地址。

因此链表中任意一个未知结点的访问都需要通过已知结点依次遍历，无法像顺序表那样通过地址计算直接访问，其访问任意未知结点的时间复杂度为 O(n)。

这种访问目标结点需要通过已知结点依次遍历的特性，使得链表成为一种只支持顺序存取而不支持随机存取的数据结构。

单链表的定义

每个结点中只包含一个指向后继结点的指针域的链表，称为单链表。

单链表的代码实现

定义

typedef struct LNode{
    // 1. 结点的数据域
    ElemType data;
    // 2. 结点的指针域（包括一个指向后继结点的指针）
    struct LNode *next;
} LNode, *LinkedList;

初始化

// InitList 初始化单链表
Status InitList(LinkedList &L) {
    // 1. 新建一个结点（头结点）并分配内存空间，让头指针指向该结点
    L = new LNode;
    // 2. 判断头指针是否为空，为空则空间分配失败，直接退出
    // if (!L) exit(OVERFLOW);  // C++ 中无需判断
    // 3. 将头结点的指针域置为空
    L->next = NULL;
    return OK;
}

销毁

// DestroyList 销毁单链表
void DestroyList(LinkedList &L) {
    // 1. 声明一个临时存储结点地址的辅助指针 p，用来暂存当前要释放的结点地址，辅助完成结点的释放
    LNode *p;
    // 2. 循环移动头指针，并用辅助指针 p 释放每个结点占用的内存空间，直到头指针为空
    while (L) {
        // 2.1 将当前结点的地址暂存到辅助指针中
        p = L;
        // 2.2 将头指针指向下一个结点
        L = L->next;
        // 2.3 释放辅助指针指向的结点占用的内存空间
        delete p;
    }
}

清空

// ClearList 清空单链表
void ClearList(LinkedList &L) {
    // 1. 声明两个辅助指针 p 和 q，一个用来暂存当前要释放的结点地址，另一个用来暂存下一个结点的地址
    LNode *p, *q;
    // 2. 让辅助指针 p 指向首元结点，清空操作从首元结点开始进行，保留头结点
    p = L->next;
    // 3. 循环移动辅助指针 p，并用辅助指针 q 释放每个结点占用的内存空间，直到辅助指针 p 为空
    while (p) {
        // 3.1 将下一个结点的地址暂存到辅助指针 q 中
        q = p->next;
        // 3.2 释放辅助指针 p 指向的结点占用的内存空间
        delete p;
        // 3.3 将辅助指针 p 指向下一个结点
        p = q;
    }
    // 4. 将头结点的指针域置为空
    L->next = NULL;
}

判空

// ListEmpty 判断单链表是否为空
Status ListEmpty(LinkedList L) {
    // 直接判断头结点的指针域是否为空返回结果即可
    if (L->next == NULL) return TRUE;
    else return FALSE;
}

求表长

// ListLength 求单链表的表长
int ListLength(LinkedList L) {
    // 1. 定义一个整型变量 length 用来计数，初始值为 0
    int length = 0;
    // 2. 定义一个辅助指针 p，指向首元结点
    LNode *p = L->next;
    // 3. 循环移动辅助指针 p，每移动一次 length 加 1，直到 p 为空
    while (p) {
        // 3.1 length 加 1
        length++;
        // 3.2 将辅助指针 p 指向下一个结点
        p = p->next;
    }
    // 4. 返回 length 的值
    return length;
}

查找

// LocateElem 按值查找元素
int LocateElem(LinkedList L, ElemType e) {
    // 1. 定义一个整型变量 i 用来表示当前查找到的位置，初始值为 1
    int i = 1;
    // 2. 定义一个辅助指针 p，指向首元结点
    LNode *p = L->next;
    // 3. 循环移动辅助指针 p，判断当前结点的数据域值是否等于目标值，如果不满足条件则继续执行查找操作
    while (p && p->data != e) {
        // 3.1 将辅助指针 p 指向下一个结点
        p = p->next;
        // 3.2 位置 i 加 1
        i++;
    }
    // 4. 如果找到目标值，返回其位置
    if (p) return i;
    // 5. 如果未找到，返回 0
    else return 0;
}

// LocateElem 按值查找元素（自定义比较函数）
int LocateElem(LinkedList L, ElemType e, bool (*compare)(ElemType, ElemType)) {
    int i = 1;
    LNode *p = L->next;
    while (p && !compare(p->data, e)) {  
        p = p->next;
        i++;
    }
    if (p) return i;
    else return 0;
}

取值

// GetElem 按位查找
Status GetElem(LinkedList L, int i, ElemType &e) {
    // 1. 定义一个整型变量 j 用来表示当前查找到的位置，初始值为 1
    int j = 1;
    // 2. 定义一个辅助指针 p，指向首元结点
    LNode *p = L->next;
    // 3. 循环移动辅助指针 p，直到找到第 i 个结点或遍历完
    while (p && j < i) {
        // 3.1 将辅助指针 p 指向下一个结点
        p = p->next;
        // 3.2 位置 j 加 1
        j++;
    }
    // 4. 判断位置是否合法，如果不合法则返回 ERROR
    if (!p || j > i) return ERROR;
    // 5. 将第 i 个结点的数据域值赋给 e
    e = p->data;
    return OK;
}

插入

// ListInsert 在单链表的第 i 个位置插入新元素 e
Status ListInsert(LinkedList &L, int i, ElemType e) {
    // 1. 定义一个整型变量 j 用来表示当前查找到的位置，初始值为 1
    int j = 1;
    // 2. 定义一个辅助指针 p，指向头结点
    LNode *p = L;
    // 3. 循环移动辅助指针 p，直到找到第 i-1 个结点或遍历完
    while (p && j < i) {
        p = p->next;
        j++;
    }
    // 4. 判断插入位置是否合法，如果不合法则返回 ERROR
    if (!p || j > i) return ERROR;
    // 5. 创建一个新结点 s
    LNode *s = new LNode;
    // 6. 将新元素的值赋给新结点的数据域
    s->data = e;
    // 7. 将新结点的指针域指向第 i 个结点
    s->next = p->next;
    // 8. 将第 i-1 个结点的指针域指向新结点
    p->next = s;
    return OK;
}

删除

// ListDelete 删除单链表的第 i 个元素，并用 e 返回其值
Status ListDelete(LinkedList &L, int i, ElemType &e) {
    // 1. 定义一个整型变量 j 用来表示当前查找到的位置，初始值为 1
    int j = 1;
    // 2. 定义一个辅助指针 p，指向头结点
    LNode *p = L;
    // 3. 循环移动辅助指针 p，直到找到第 i-1 个结点或遍历完
    while (p->next && j < i) {
        p = p->next;
        j++;
    }
    // 4. 判断删除位置是否合法，如果不合法则返回 ERROR
    if (!p->next || j > i) return ERROR;
    // 5. 用 q 指向待删除的第 i 个结点
    LNode *q = p->next;
    // 6. 将待删除结点的数据域值赋给 e
    e = q->data;
    // 7. 将第 i-1 个结点的指针域指向第 i+1 个结点
    p->next = q->next;
    // 8. 释放待删除结点的内存空间
    delete q;
    return OK;
}

单循环链表的定义

将单链表的尾结点的指针域指向链表的第一个结点（带头结点时为头结点，不带头结点时为首元结点），使整个单链表形成一个首尾相接的闭合环状结构，称为单循环链表。

定义

销毁

void DestroyList(LinkedList &L) {
    LNode *p, *q;
    // 先跳过头结点，最后再单独释放头结点
    p = L->next;
    // 循环结束的条件是辅助指针 p 回到头结点
    while (p != L) {
        q = p->next;
        delete p;
        p = q;
    }
     // 最后释放头结点
    delete L;
    // 将头指针置空
    L = NULL; 
}
