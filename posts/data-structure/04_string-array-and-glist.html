（四）串、数组和广义表

串的定义

$$ s = a_1a_2...a_n $$

串（String）：由 n(n≥0) 个任意字符组成的有限序列。

  • 其中 n 为串长，n=0 时称为空串。空串用 \(Φ\) 表示。
  • 串名：s 是串的名。
  • 串值：用双引号括起来的字符序列是串的值。
  • 子串：串中任意个连续的字符组成的子序列称为该串的子串。
  • 主串：包含子串的串相应地称为主串。
  • 字符位置：字符在序列中的序号为该字符在串中的位置。
  • 子串位置：子串在主串中的位置则以子串的第一个字符在主串中的位置来表示。
  • 空格串：由一个或多个空格组成的串称为空格串。
  • 串相等：当且仅当两个串的长度相等并且各个对应位置上的字符都相同时，这两个串才是相等的。

串的模式匹配

BF算法

BF（Brute Force）：暴力破解。

int BF(SString S, SString T) {
    int i = 1;  // 主串指针
    int j = 1;  // 子串指针

    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) {
            // 字符匹配，指针同时后移
            i++;
            j++;
        } else {
            // 字符不匹配，指针回退
            i = i - j + 2;  // 主串回退到上一次起始位置的下一个
            j = 1;          // 子串回到开头
        }
    }

    if (j > T.length) {
        return i - T.length;  // 匹配成功，返回起始位置
    } else {
        return -1;            // 匹配失败
    }
}

KMP算法

KMP（Knuth、Morris & Pratt）：改进算法。

前缀：对于一个字符串 T，它的前缀是指不包含最后一个字符的子串。

例如：T = "ababc"，其前缀包括："a", "ab", "aba", "abab"

后缀：对于一个字符串 T，它的后缀是指不包含第一个字符的子串。

例如：T = "ababc"，其后缀包括："c", "bc", "abc", "babc"

最长公共前后缀：对于一个字符串 T，它的最长公共前后缀是指既是 T 的前缀又是 T 的后缀的最长子串。

例如：T = "a"，其没有最长公共前后缀，长度为0。

例如：T = "ab"，其没有最长公共前后缀，长度为0。

例如：T = "aba"，其最长公共前后缀是 "a"，长度为1。

例如：T = "abab"，其最长公共前后缀是 "ab"，长度为2。

例如：T = "ababc"，其没有最长公共前后缀，长度为0。

前缀表：对于一个字符串 T，它的前缀表是一个数组，其中每个元素表示对应位置的最长公共前后缀的长度。

例如：T = "ababc"，其前缀表为 [0, 0, 1, 2, 0]。

next数组：对于一个字符串 T，它的next数组是前缀表的改进版本，用于优化模式匹配过程。

next 数组是前缀表的变形，没有统一的标准定义，最常见的有三种：

  1. 标准 next 数组：与前缀表完全相同
  2. 严蔚敏版 next 数组：前缀表整体右移一位，第一个元素设为-1
  3. 优化版 nextval 数组：在严蔚敏版基础上解决了连续相同字符的冗余比较问题
// 计算标准版next数组（=前缀表）
// next[i] = 子串 T[0..i] 的最长相等前后缀的长度
void GetNext(SString T, int next[]) {
    next[0] = 0;  // 单个字符没有前后缀，最长相等长度为0
    int j = 0;    // j表示当前最长相等前后缀的长度

    // i从1开始，因为i=0已经初始化
    for (int i = 1; i < T.length; ++i) {
        // 不匹配时，j回退到上一个可能的最长前后缀位置
        while (j > 0 && T.ch[i] != T.ch[j]) {
            j = next[j - 1];  // 关键：回退到j-1位置的前缀表值
        }

        // 匹配成功，最长前后缀长度+1
        if (T.ch[i] == T.ch[j]) {
            j++;
        }

        next[i] = j;  // 记录当前位置的最长相等前后缀长度
    }
}

// 标准版KMP匹配算法
// 返回：匹配成功返回起始位置（1开始，与之前BF/KMP保持一致），失败返回-1
int KMP(SString S, SString T, int next[]) {
    // 边界条件：模式串为空直接返回1
    if (T.length == 0) return 1;
    // 模式串比主串长直接返回-1
    if (T.length > S.length) return -1;

    int j = 0;  // 模式串指针
    for (int i = 0; i < S.length; ++i) {
        // 不匹配时，模式串回退
        while (j > 0 && S.ch[i] != T.ch[j]) {
            j = next[j - 1];  // 关键：回退到j-1位置的前缀表值
        }

        // 匹配成功，两个指针同时后移
        if (S.ch[i] == T.ch[j]) {
            j++;
        }

        // 模式串遍历完成，匹配成功
        if (j == T.length) {
            return i - T.length + 1;  // 转换为1开始的位置
        }
    }

    return -1;  // 匹配失败
}

// 计算标准next数组（严蔚敏版）
void GetNext(SString T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;  // 严蔚敏教材1开始计数，next[1]=0
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++;
            j++;
            next[i] = j;
        } else {
            j = next[j];  // 回退到上一个可能的位置
        }
    }
}

// 计算优化版nextval数组
void GetNextval(SString T, int nextval[]) {
    int i = 1, j = 0;
    nextval[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++;
            j++;
            // 优化：如果当前字符与回退后的字符相同，则继续回退
            if (T.ch[i] != T.ch[j]) {
                nextval[i] = j;
            } else {
                nextval[i] = nextval[j];
            }
        } else {
            j = nextval[j];
        }
    }
}

// KMP匹配算法（严蔚敏版）
// 输入：主串S，模式串T，next数组
// 返回：匹配成功返回起始位置（1开始），失败返回-1
int KMP(SString S, SString T, int next[]) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) {
            i++;
            j++;
        } else {
            j = next[j];  // 模式串回退，主串i不回退！这是KMP的核心优势
        }
    }
    if (j > T.length) {
        return i - T.length;  // 匹配成功，返回起始位置
    } else {
        return -1;            // 匹配失败
    }
}

数组的定义

arr1 = [1,2,3,4,5]
arr2 = [ [1, 2, 3], [4, 5, 6], [7, 8, 9] ]

数组（Array）：是由类型相同的数据元素构成的有序集合，是线性表的推广。

  • 数组中的每个元素称为数组元素。
  • 维数：数组中每个元素受 n(n≥1) 个线性关系的约束，n 就是数组的维数。（n = 1 就是一维数组，n = 2 就是二维数组，以此类推。）
  • 维界：数组在某一维度上可容纳元素的总个数（即该维的长度）。
  • 下标：数组元素在数组中的位置\(i_1, i_2, ..., i_n\)称为下标，可以通过下标访问该数据元素。（下标从 0 开始。）

举个例子：

  1. int a[10];
  • 维数：1
  • 维界：10
  • 下标范围：[0, 9]
  1. int b[3][5];
  • 维数：2
  • 第一维界：3 ，第二维界：5
  • 下标范围：
    • 第一维下标范围：[0, 2]
    • 第二维下标范围：[0, 4]

数组的顺序存储

由于数组一般不做插入或删除操作，也就是说，一旦建立了数组，则结构中的数据元素个数和元素之间的关系就不再发生变动。因此，采用顺序存储结构表示数组比较合适。

另外，由于数组可以是多维的，但存储数据元素的内存单元地址是一维的，因此，在存储数组结构之前，需要解决将多维关系映射到一维关系的问题。

一维数组的顺序存储

对于一维数组，直接将数组元素依次存储在连续的内存单元中即可。

数组元素 \(a[i]\) 的存储地址为：\(LOC(a[i]) = LOC(a[0]) + (i-1) \times sizeof(ElemType)\)

二维数组的顺序存储

对于二维数组，可有两种存储方式：一种是以列序为主序的存储方式，另一种是以行序为主序的存储方式。

  • 以行序为主序时，数组元素 \(a[i][j]\) 的存储地址为：\(LOC(a[i][j]) = LOC(a[0][0]) + (i×n+j) \times sizeof(ElemType)\)
  • 以列序为主序时，数组元素 \(a[i][j]\) 的存储地址为：\(LOC(a[i][j]) = LOC(a[0][0]) + (j×m+i) \times sizeof(ElemType)\)

广义表的定义

$$ LS = (a_1,a_2,...,a_n) $$

广义表：是 n(n≥0) 个数据元素构成的有限序列，是线性表的推广。

  • 在线性表中，\(a_i(1 ≤ i ≤ n)\) 只限于是单个元素。而在广义表中，\(a_i\) 可以是单个元素，也可以是广义表，分别称为广义表LS的原子和子表。

习惯上，用大写字母表示广义表的名称，用小写字母表示原子。

举个例子：

  • A = ()。A 是一个空表，长度为 0。
  • B = (())。B 是含有一个元素的广义表，长度为 1，这个元素是一个空的广义表。
  • C = (a, b, c)。C 是一个长度为 3 的广义表，这三个元素a、b、c都是原子。
  • D = (A, B ,C)。D 是一个长度为 3 的广义表，这三个元素A、B、C都是子表。
  • E = (a, (b, c), D)。E 是一个长度为 3 的广义表，这三个元素分别是原子a、子表(b, c)和子表D。
  • F = (a, F)。F 是一个递归的表，长度为 2。F 相当于一个无限的广义表 F = (a,(a,(a,...)))。
