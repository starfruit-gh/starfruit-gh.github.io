（八）排序

排序的基本概念

  • 排序：是按关键字的非递减或非递增顺序对一组记录重新进行排列的操作。
  • 排序的稳定性：相等的记录在排序前后的相对位置保持不变就是稳定的，否则就是不稳定的。
  • 内部排序：指的是待排序记录全部存放在计算机内存中进行排序的过程。
  • 外部排序：指的是待排序记录的数量很大，以致内存一次不能容纳全部记录，在排序过程中尚需对外存进行访问的排序过程。

func StraightInsertionSort(arr []int) {
    n := len(arr)
    if n <= 1 {
        return
    }
    for i := 1; i < n; i++ {
        insertVal := arr[i]
        insertIndex := i - 1
        for insertIndex >= 0 && insertVal < arr[insertIndex] {
            arr[insertIndex+1] = arr[insertIndex]
            insertIndex--
        }
        arr[insertIndex+1] = insertVal
    }
}
折半插入排序
func BinaryInsertionSort(arr []int) {
    n := len(arr)
    if n <= 1 {
        return
    }
    for i := 1; i < n; i++ {
        insertVal := arr[i]
        low, high := 0, i-1
        for low <= high {
            mid := low + (high-low)/2
            if insertVal < arr[mid] {
                high = mid - 1
            } else {
                low = mid + 1
            }
        }
        for j := i - 1; j >= low; j-- {
            arr[j+1] = arr[j]
        }
        arr[low] = insertVal
    }
}
希尔排序
func ShellSort(arr []int) {
    n := len(arr)
    if n <= 1 {
        return
    }
    for gap := n / 2; gap > 0; gap /= 2 {
        for i := gap; i < n; i++ {
            insertVal := arr[i]
            insertIndex := i
            for insertIndex >= gap && insertVal < arr[insertIndex-gap] {
                arr[insertIndex] = arr[insertIndex-gap]
                insertIndex -= gap
            }
            arr[insertIndex] = insertVal
        }
    }
}

func BubbleSort(arr []int) {
    n := len(arr)
    if n <= 1 {
        return
    }
    for i := 0; i < n-1; i++ {
        swapped := false
        for j := 0; j < n-1-i; j++ {
            if arr[j] > arr[j+1] {
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = true
            }
        }
        if !swapped {
            break
        }
    }
}
快速排序
func QuickSort(arr []int) {
    if len(arr) <= 1 {
        return
    }
    quickSort(arr, 0, len(arr)-1)
}

func quickSort(arr []int, low, high int) {
    if low < high {
        pivotIndex := partition(arr, low, high)
        quickSort(arr, low, pivotIndex)
        quickSort(arr, pivotIndex+1, high)
    }
}

func partition(arr []int, low, high int) int {
    pivot := arr[low+(high-low)/2]
    for {
        for arr[low] < pivot {
            low++
        }
        for arr[high] > pivot {
            high--
        }
        if low >= high {
            return high
        }
        arr[low], arr[high] = arr[high], arr[low]
        low++
        high--
    }
}

func SelectionSort(arr []int) {
    n := len(arr)
    if n <= 1 {
        return
    }
    for i := 0; i < n-1; i++ {
        minIndex := i
        for j := i + 1; j < n; j++ {
            if arr[j] < arr[minIndex] {
                minIndex = j
            }
        }
        arr[i], arr[minIndex] = arr[minIndex], arr[i]
    }
}
堆排序
func HeapSort(arr []int) {
    n := len(arr)
    if n <= 1 {
        return
    }

    buildMaxHeap(arr)

    for i := n - 1; i > 0; i-- {
        arr[0], arr[i] = arr[i], arr[0]
        heapify(arr, i, 0)
    }
}

func buildMaxHeap(arr []int) {
    n := len(arr)
    for i := n/2 - 1; i >= 0; i-- {
        heapify(arr, n, i)
    }
}

func heapify(arr []int, heapSize, root int) {
    largest := root
    left := 2*root + 1
    right := 2*root + 2

    if left < heapSize && arr[left] > arr[largest] {
        largest = left
    }
    if right < heapSize && arr[right] > arr[largest] {
        largest = right
    }

    if largest != root {
        arr[root], arr[largest] = arr[largest], arr[root]
        heapify(arr, heapSize, largest)
    }
}

归并排序

二路归并排序
func MergeSort(arr []int) {
    if len(arr) <= 1 {
        return
    }
    mid := len(arr) / 2
    left := arr[:mid]
    right := arr[mid:]
    MergeSort(left)
    MergeSort(right)
    merge(arr, left, right)
}

func merge(arr, left, right []int) {
    i, j, k := 0, 0, 0
    temp := make([]int, len(left)+len(right))
    for i < len(left) && j < len(right) {
        if left[i] <= right[j] {
            temp[k] = left[i]
            i++
        } else {
            temp[k] = right[j]
            j++
        }
        k++
    }
    for i < len(left) {
        temp[k] = left[i]
        i++
        k++
    }
    for j < len(right) {
        temp[k] = right[j]
        j++
        k++
    }
    copy(arr, temp)
}

func BucketSort(arr []int) {
    if len(arr) <= 1 {
        return
    }

    minVal, maxVal := arr[0], arr[0]
    for _, v := range arr {
        if v < minVal {
            minVal = v
        }
        if v > maxVal {
            maxVal = v
        }
    }

    bucketSize := 10
    bucketCount := (maxVal-minVal)/bucketSize + 1
    buckets := make([][]int, bucketCount)

    for _, v := range arr {
        index := (v - minVal) / bucketSize
        buckets[index] = append(buckets[index], v)
    }

    index := 0
    for _, bucket := range buckets {
        // 使用任何内部排序算法来实现桶内排序
        StraightInsertionSort(bucket)
        
        for _, v := range bucket {
            arr[index] = v
            index++
        }
    }
}

// 原生计数排序（仅支持非负整数）
func CountingSortNonNegative(arr []int) {
    if len(arr) <= 1 {
        return
    }

    maxVal := arr[0]
    for _, v := range arr {
        if v > maxVal {
            maxVal = v
        }
    }

    count := make([]int, maxVal+1)
    for _, v := range arr {
        count[v]++
    }

    index := 0
    for i, cnt := range count {
        for ; cnt > 0; cnt-- {
            arr[index] = i
            index++
        }
    }
}

// 支持负数的计数排序
func CountingSort(arr []int) {
    if len(arr) <= 1 {
        return
    }

    minVal, maxVal := arr[0], arr[0]
    for _, v := range arr {
        if v < minVal {
            minVal = v
        }
        if v > maxVal {
            maxVal = v
        }
    }

    offset := -minVal
    temp := make([]int, len(arr))
    for i, v := range arr {
        temp[i] = v + offset
    }

    CountingSortNonNegative(temp)

    for i, v := range temp {
        arr[i] = v - offset
    }
}

type Node struct {
    Val  int64
    Next *Node
}

type Queue struct {
    Head *Node
    Tail *Node
}

func (q *Queue) Enqueue(val int64) {
    newNode := &Node{Val: val}
    if q.Tail == nil {
        q.Head = newNode
        q.Tail = newNode
    } else {
        q.Tail.Next = newNode
        q.Tail = newNode
    }
}

func (q *Queue) Dequeue() (int64, bool) {
    if q.Head == nil {
        return 0, false
    }
    val := q.Head.Val
    q.Head = q.Head.Next
    if q.Head == nil {
        q.Tail = nil
    }
    return val, true
}

func (q *Queue) IsEmpty() bool {
    return q.Head == nil
}

// 原生基数排序（仅支持非负整数）
func RadixSortNonNegative(arr []int64) {
    if len(arr) <= 1 {
        return
    }
    maxVal := arr[0]
    for _, v := range arr {
        if v > maxVal {
            maxVal = v
        }
    }
    for exp := int64(1); maxVal/exp > 0; exp *= 10 {
        queues := make([]*Queue, 10)
        for i := range queues {
            queues[i] = &Queue{}
        }
        for _, v := range arr {
            digit := (v / exp) % 10
            queues[digit].Enqueue(v)
        }
        idx := 0
        for _, t := range queues {
            for !t.IsEmpty() {
                val, _ := t.Dequeue()
                arr[idx] = val
                idx++
            }
        }
    }
}

// 支持负数的整数基数排序
func RadixSortInt(arr []int64) {
    if len(arr) <= 1 {
        return
    }
    var neg, nonNeg []int64
    for _, v := range arr {
        if v < 0 {
            neg = append(neg, -v)
        } else {
            nonNeg = append(nonNeg, v)
        }
    }
    RadixSortNonNegative(neg)
    RadixSortNonNegative(nonNeg)
    for i, j := 0, len(neg)-1; i < j; i, j = i+1, j-1 {
        neg[i], neg[j] = neg[j], neg[i]
    }
    idx := 0
    for _, v := range neg {
        arr[idx] = -v
        idx++
    }
    for _, v := range nonNeg {
        arr[idx] = v
        idx++
    }
}

// 辅助函数：获取浮点数小数位数
func getDecimals(x float64) int {
    s := strconv.FormatFloat(x, 'f', 6, 64)
    pos := strings.Index(s, ".")
    if pos == -1 {
        return 0
    }
    return len(strings.TrimRight(s[pos+1:], "0"))
}

// 支持正负 + 小数的浮点数基数排序
func RadixSortFloat(arr []float64) {
    if len(arr) <= 1 {
        return
    }
    minVal := arr[0]
    for _, v := range arr {
        if v < minVal {
            minVal = v
        }
    }
    offset := 0.0
    if minVal < 0 {
        offset = -minVal
    }
    maxd := 0
    for _, v := range arr {
        if d := getDecimals(v); d > maxd {
            maxd = d
        }
    }
    scale := math.Pow(10, float64(maxd))
    temp := make([]int64, len(arr))
    for i, v := range arr {
        temp[i] = int64(math.Round((v + offset) * scale))
    }
    RadixSortNonNegative(temp)
    for i, v := range temp {
        arr[i] = float64(v)/scale - offset
    }
}

外部排序

将外存上含 n 个记录的文件分成若干长度为 l 的子文件或段（segment），依次读入内存并利用有效的内部排序方法对它们进行排序，并将排序后得到的有序子文件重新写入外存，通常称这些有序子文件为归并段。

假设内存中只有两个输入缓冲区、一个输出缓冲区，如何将外存中磁盘块0-7进行排序？

首先，通过内部排序将磁盘块0、1，2、3，4、5，6、7通过内部排序，生成4个归并段。

然后，利用归并排序的方法将4个归并段进行合并，最终得到一个有序文件。

举个例子：

归并树

外部排序的总时间=内部排序的时间+外存信息读/写的时间+内部归并的时间。

其中，影响最大的部分就是：外存信息读/写的时间（硬盘I/O）。

对于上述归并树：总I/O次数为：8*4+16*2+32+8*4=128。

多路归并

一般地，对r个初始归并段，做k路归并排序，设归并趟数为s，则\(k^s≥r\)。可见，当k增大时，s即可减少，进而减少IO次数，从而减少外排时间。

败者树

由于使用多路排序会导致比较次数增加，因此引入败者树来优化比较过程。

算法步骤如下：

  1. 初始化：将所有叶子节点初始化为各个输入序列的第一个元素，其他节点初始化为无穷大。
  2. 比较：从叶子节点开始，每次比较一对兄弟节点，并将较大的元素所在段号保存在父节点中。同时，将较小的元素（即“胜者”）向上传递，与其他胜者比较，不断重复步骤2，直至到达根节点。
  3. 输出：根节点中的元素就是当前最小的元素，将其输出。
  4. 更新：将刚刚输出的元素替换为其所在序列的下一个元素。如果该序列已经没有元素了，就将其替换为无穷大。
  5. 重构败者树：从刚刚更新的叶子节点开始，重新执行步骤2和步骤3，直到所有元素都被输出。

倘若有四个归并段，我们采用败者树进行归并。

置换选择排序

减少初始归并段的个数也可以减少归并所需要的趟数，可以通过增长初始归并段的长度来减少初始归并段的个数。

假设初始待排序文件为FI，初始归并段文件为输出文件FO，内存工作区为WA(work area)，FO与WA的初始状态为空，并假设内存工作区WA的容量可容纳w个记录，以下是置换选择排序的算法步骤：

  1. 从FI输入w个记录到工作区 WA，
  2. 从 WA 中选出其中关键字最小的记录，记为 MINIMAX
  3. 将MINIMAX输出到FO中去。
  4. 若FI不为空，则从FI输入下一个记录到WA中
  5. 从 WA 中选出关键字比 MINIMAX的关键字大的最小记录作为新的 MINIMAX。
  6. 重复步骤 3 ~ 5，直至 WA中选不出新的 MINIMAX为止，由此得到一个初始归并段，输出个归并段的结束标记到 FO。
  7. 重复步骤 2 ~ 6，直至 WA 为空。由此得到全部归并段。

最佳归并树

置换选择排序会生成长度不一样的初始归并段，每个归并段所占的磁盘块数可能不同，归并过程也可能不同。

这棵归并树的带权路径长度 WPL = 2*1 + (5+1+6+2) * 3 = 44 = 读磁盘的次数 = 写磁盘的次数。

可以使用哈夫曼树的思想来进行优化。

最佳归并树 \(WPL_{min} = (1+2)*4 + 2*3 +5*2 + 6*1 = 34\)

读磁盘次数 = 写磁盘次数 = 34 次；总的磁盘 I/O 次数 = 68

对于多路归并，同样可以使用哈夫曼树的思想来构建最佳归并树。

但是，注意：对于k叉归并，若初始归并段的数量无法构成严格的Κ叉归并树，则需要补充几个长度为0的“虚段”，再进行k叉哈夫曼树的构造。

例如：

k叉的最佳归并树一定是一棵严格的k叉树，即树中只包含度为k、度为0的结点。

设度为k的结点有 \(n_k\) 个，度为0的结点有 \(n_0\) 个，归并树总结点数=\(n\) 则：

初始归并段数量+虚段数量=\(n_0\)

$$ \begin{array}{c} n = n_0 + n_k \\ k n_k = n - 1 \end{array} \rightarrow n_0 = (k-1)n_k + 1 \;\rightarrow\; n_k = \frac{n_0 - 1}{k - 1} $$
  1. 若 \((\text{初始归并段数量} - 1) \% (k-1) = 0\)，说明刚好可以构成严格k叉树，此时不需要添加虚段
  2. 若 \((\text{初始归并段数量} - 1) \% (k-1) = u \neq 0\)，则需要补充 \((k-1) - u\) 个虚段
