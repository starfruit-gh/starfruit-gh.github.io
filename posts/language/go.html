Go语言

基础

标识符

  1. 定义

    2. 标识符（Identifier）：是程序员自定义的、用于唯一标识程序中各类实体（Entity）的字符序列。这些实体包括但不限于：

    • 变量（如age）
    • 常量（如MaxSize）
    • 函数/方法（如GetUserByID）
    • 结构体（如User）
    • 接口（如Reader）
    • 包（如fmt）
    • ...

    通俗来说，标识符就是代码里各种 “东西” 的名字。

  2. 作用

    3. 标识符是内存地址的抽象替代。程序运行时，数据和指令都存储在内存中，需要通过对应的地址进行操作，但是使用内存地址（如 0x3A4F）极易出错且难以记忆。因此可以通过标识符直接操作对应的数据，编译器会自动完成标识符到底层内存位置的映射与转换。这样就只需关心“是什么数据”，而无需关心“数据在哪儿”，极大提高了代码的可读性和可维护性。

  3. 语法规则（Go语言规则）
    1. 标识符由Unicode字符的 字母、数字以及下划线 组成，不能以数字开头
    2. 标识符不能包含特殊字符。这些特殊字符包括但不限于：
      • 货币符号：$、¥、€等
      • 标点符号：?、:、;、"、'、、、。等
      • 算术/逻辑运算符：+、-、*、/、%、&、|、!、^、~、=、>、<等
      • 分隔类字符：-、.、\、/ 等
      • 各类括号：()、[]、{}、<> 等
      • ...
    3. 标识符不能是Go语言的关键字
  4. 命名规范（Go语言规范）
    • 项目名：全小写，多个单词之间用连字符(-)分隔。例如，go-zero、go-redis等。
    • 目录名：仅由小写字母组成，严禁使用大写字母、驼峰、下划线（_）或连字符（-）。建议保持目录名与包名一致，简短且有语义。例如，auth✅authentication❌、model✅Models❌、middleware✅middle_ware❌middle-ware❌等。
    • 文件名：全小写，多个单词之间用下划线(_)分隔，即蛇形命名。例如，task_queue.go、auth_test.go等。
    • 标识符：一般使用驼峰式命名，其中首字母大小写控制可见性：大写导出(Public)、小写包内私有(Private)。需要特别说明的是，
      • 包名：建议包名与目录名保持一致，避免导入路径和实际包名脱节。当目录名与包名不一致时，其他包下的go程序导入该包时，导包语句的路径为该包的目录名，但在程序内调用该包的函数时使用的是该包的包名。
      • 缩略词：对于ID、URL、HTTP、API、JSON等通用缩略词，命名时保持完整的大小写，不使用驼峰拼写。例如，UserID✅UserId❌、HTTPHandler✅HttpHandler❌等。
      • 变量：作用域越小，变量名越短：循环、短函数内用i、j、err、u 这类短名；作用域越大，变量名描述性越强：包级变量、全局变量语义要完整。例如maxConnectionNum。
      • 常量：在Go中不推荐常量使用 全大写 + 下划线 的命名风格，常量命名规则与变量完全一致，采用驼峰式，首字母控制可见性。
      • 构造函数：构造函数推荐使用 New 前缀，例如，NewUser、NewStudent等。
      • 接收者：一般为类型本身的缩写（通常是一两个字母的长度）。例如，func (s Student)、func (t *Teacher)等。
      • 接口：只包含一个方法的接口应当以该方法的名称加上-er后缀来命名，例如，Reader、Writer等。
      • ...

关键字

关键字（Keyword）：是编程语言中预定义的、具有特殊语法含义的保留词汇，直接参与代码的结构化。它们被编译器或解释器用于解析代码逻辑。并且通常不允许被开发者用作自定义标识符或改变其内置语义。

    chan         else         goto         package      switch
    const        fallthrough  if           range        type
    continue     for          import       return       var

预定义标识符

预定义标识符（Pre-defined Identifier）：是编程语言预先声明好、并赋予特定含义或默认值的名称。预定义标识符不是关键字，本质上依然是标识符，且可以赋值覆盖，但不建议。

Constants:   true  false  iota  nil

    Types:   int  int8  int16  int32  int64
             uint  uint8  uint16  uint32  uint64  uintptr
             float32  float64  complex64  complex128
             bool  byte  rune  string  error

Functions:   make  len  cap  new  append  copy  close  delete
             complex  real  imag
             panic  recover

在Go语言中，使用预定义标识符作为标识符会导致标识符的原有功能被覆盖，从而引发错误或逻辑混乱。

// 1.覆盖内建常量
func example() {
    true := false     // 覆盖预定义常量 true
    if true {         // 实际条件为 false
        fmt.Println("执行 A")
    } else {
        fmt.Println("执行 B") // 实际输出
    }
}
// true 被赋值为 false，导致条件逻辑与预期相反，产生隐蔽的逻辑错误。

// 2.覆盖内建类型
func example() {
    var int = 10    // 变量名覆盖了内置类型 int
    var x int       // 错误！此时 int 是变量，不是类型
    fmt.Println(x)
}
// int 在函数内部被声明为变量，导致无法再使用 int 类型声明其他变量，编译时报错 type int is not an expression.

// 3.覆盖内建函数
func main( ) {
    len := 5             // 变量名覆盖了内置函数 len
    s := []int{1, 2, 3}
    fmt.Println(len(s)) // 错误！len 是变量，无法调用
}
// len 被覆盖为整型变量后，尝试调用 len(s) 会触发编译错误 cannot call non-function len.

    //4.修改变量的值

    var e uint8 = 10

        f uint16 = 11
        g uint32 = 12
        h uint64 = 13
    )
    fmt.Println(f, g, h)

    var i, j = 14, "abc"
    fmt.Println(i, j)

    var k = 15
    var l = "def"
    fmt.Println(k, l)

    _, o := 19, 20

    //二、常量

    fmt.Println(PI)

        P float64 = 1.23
        Q byte    = 'i'
        R string  = "jkl"
    )
    fmt.Println(P, Q, R)
    
    //3.一次初始化多个常量(可以是不同类型的常量)
    const S, T = 21, "mn"
    fmt.Println(S, T)

    const U = 22
    const V = "opq"
    fmt.Println(U, V)
    
    //5.const 与 iota
    //批量初始化时，未初始化值则表示与上一行值相同
    const (
        W = 100
        X
        Y
    )
    fmt.Println(W, X, Y)
    //iota 在 const 出现时，iota 从 0 开始，每新增一行常量声明 iota 自动递增
    const (
        Z1 = iota
        Z2
        Z3
    )
    fmt.Println(Z1, Z2, Z3)
    //可以使用 _ 跳过值
    const (
        Z4 = iota
        Z5
        _
        Z6
    )
    fmt.Println(Z4, Z5, Z6)
    //可以插入某些值
    const (
        Z7 = iota
        Z8 = 100
        Z9 = iota
        Z10
    )
    fmt.Println(Z7, Z8, Z9, Z10)
    //多个 iota 定义在一行
    const (
        Z11, Z12 = iota + 1, iota + 2
        Z13, Z14
        Z15, Z16
    )
    fmt.Println(Z11, Z12, Z13, Z14, Z15, Z16)
    //定数量级
    const (
        _  = iota
        KB = 1 << (10 * iota)
        MB = 1 << (10 * iota)
        GB = 1 << (10 * iota)
        TB = 1 << (10 * iota)
        PB = 1 << (10 * iota)
    )
    fmt.Printf("KB: %v, MB: %v, GB: %v, TB: %v, PB: %v, ", KB, MB, GB, TB, PB)
}

package main

import (
    "fmt"
    "reflect"
)

/*
    整型：
        uint8 uint16 uint32 uint64
        int8 int16 int32 int64
        uint int uintptr
    浮点型：
        float32 float64
    复数：
        complex64 complex128
    布尔型：
        bool
    字符型：
        byte(uint8) rune(int32)
    字符串：
        string
    
    array、slice、map、func、pointer、struct、interface、error、channel
*/

func main() {
    //1.各数据类型的 零值 以及 内存空间的初始化情况
    var (
        a int
        b uint
        c float32
        d float64
        e complex64
        f complex128
        g bool
        h byte
        i rune
        j string

        //数组
        k [3]int
        //切片
        l []int
        //map
        m map[int]string
        //func(匿名、无参、无返回值)
        n func()
        //指针
        o *int
        //结构体(匿名、无属性)
        p struct{}
        //接口(匿名、空接口)
        q interface{}
        //error
        r error
        //channel
        s chan int
    )
    vars := []interface{}{&a, &b, &c, &d, &e, &f, &g, &h, &i, &j, &k, &l, &m, &n, &o, &p, &q, &r, &s}
    for _, v := range vars {
        val := reflect.ValueOf(v).Elem()
        typ := val.Type()
        kind := typ.Kind()
        value := getValueString(val)
        addr := getAddressInfo(v, val)
        fmt.Printf("Type: %-15s Kind: %-10s Value: %-10v Address: %s\n", typ, kind, value, addr)
    }
}

func getAddressInfo(ptr interface{}, val reflect.Value) string {
    if isNilType(val) && val.IsNil() {
        return "未指向有效的底层数据结构"
    }
    return fmt.Sprintf("%p", ptr)
}

func isNilType(val reflect.Value) bool {
    switch val.Kind() {
    case reflect.Slice, reflect.Map, reflect.Func, reflect.Ptr, reflect.Interface, reflect.Chan:
        return true
    default:
        return false
    }
}

func getValueString(val reflect.Value) string {
    switch val.Kind() {
    case reflect.Slice, reflect.Map, reflect.Func, reflect.Ptr, reflect.Interface, reflect.Chan:
        if val.IsNil() {
            return "nil"
        }
    }
    return fmt.Sprintf("%v", val.Interface())
}

package main

import "fmt"

func main() {
    // 1.声明
    var arr1 [3]int
    fmt.Println("arr1:", arr1)

    // 2.初始化
    // 方式一：
    var arr2 = [3]int{1, 2, 3}
    // 方式二：
    var arr3 = [...]string{"北京", "上海", "广东", "深圳"}
    // 方式三：
    var arr4 = [3]int{1: 2, 2: 3}
    var arr5 = [...]string{1: "上海", 3: "深圳"}
    fmt.Println("arr2:", arr2)
    fmt.Println("arr3:", arr3)
    fmt.Println("arr4:", arr4)
    fmt.Println("arr5:", arr5)

    // 3.遍历
    // 方式一：
    fmt.Print("arr3: ")
    for i := 0; i < len(arr3); i++ {
        fmt.Print(arr3[i], " ")
    }
    fmt.Println()
    // 方式二：
    fmt.Print("arr3: ")
    for _, res := range arr3 {
        fmt.Print(res, " ")
    }
    fmt.Println()

    // 4.CRUD
    // 改
    arr3[2] = "杭州"
    fmt.Println("改: arr3:", arr3)
    // 查
    fmt.Println("查: arr3:", arr3[0], arr3[1], arr3[2], arr3[3])
}

package main

import "fmt"

func main() {
    //1.声明
    var s1 []int
    fmt.Println("s1:", s1)

    //2.初始化
    //方式一：
    var s2 = []int{1, 2, 3}
    //方式二：
    var s3 = []int{2: 1, 5: 6}
    //方式三(切片表达式)：
    var arr1 = [5]int{1, 2, 3, 4, 5}
    var s4 = arr1[1:3]
    var s5 = arr1[2:]
    var s6 = arr1[:3]
    var s7 = arr1[:]
    var s8 = arr1[1:4:4] //a[low : high : max]，cap=max-low
    //方式四(make函数)：
    var s9 = make([]string, 0)
    var s10 = make([]string, 0, 10)
    var s11 = make([]string, 5, 10)
    fmt.Println("s2:", s2)
    fmt.Println("s3:", s3)
    fmt.Printf("s4: %v type:%T len:%d cap:%d\n", s4, s4, len(s4), cap(s4))
    fmt.Printf("s5: %v type:%T len:%d cap:%d\n", s5, s5, len(s5), cap(s5))
    fmt.Printf("s6: %v type:%T len:%d cap:%d\n", s6, s6, len(s6), cap(s6))
    fmt.Printf("s7: %v type:%T len:%d cap:%d\n", s7, s7, len(s7), cap(s7))
    fmt.Printf("s8: %v type:%T len:%d cap:%d\n", s8, s8, len(s8), cap(s8))
    fmt.Printf("s9: len:%d cap:%d\n", len(s9), cap(s9))
    fmt.Printf("s10: len:%d cap:%d\n", len(s10), cap(s10))
    fmt.Printf("s11: len:%d cap:%d\n", len(s11), cap(s11))

    //3.遍历
    //方式一:
    fmt.Print("s2: ")
    for i := 0; i < len(s2); i++ {
        fmt.Print(s2[i], " ")
    }
    fmt.Println()
    //方式二:
    fmt.Print("s2: ")
    for _, res := range s2 {
        fmt.Print(res, " ")
    }
    fmt.Println()

    //4.CRUD
    //增
    s9 = append(s9, "a", "b", "c")
    fmt.Println("增: s9:", s9)
    //删
    s9 = append(s9[:1], s9[2:]...)
    fmt.Println("删: s9:", s9)
    //改
    s9[0] = "A"
    fmt.Println("改: s9:", s9)
    //查
    fmt.Println("查: s9:", s9[0], s9[1])

    //5.判空(要用 len(s)==0,不能用 s==nil)
    fmt.Println("s1是否为空:", len(s1) == 0)
    fmt.Println("s2是否为空:", len(s2) == 0)

    //6.赋值拷贝、copy()函数
    a := []int{1, 2, 3, 4, 5}
    b := a //切片赋值，底层数组共用
    c := make([]int, 5)
    copy(c, a) //切片赋值拷贝，底层数组不共用
    fmt.Println("a:", a)
    fmt.Println("b:", b)
    fmt.Println("c:", c)
    a[0] = 100
    fmt.Println("a:", a)
    fmt.Println("b:", b)
    fmt.Println("c:", c)
}

package main

import "fmt"

func main() {
    //1.声明
    var map1 map[int]string
    fmt.Println("map1:", map1)

    //2.初始化
    //方式一：
    var map2 = map[int]string{
        1: "zhangsan",
        2: "lisi",
        3: "wangwu",
    }
    //方式二(make函数)：
    var map3 = make(map[int]string, 10)
    fmt.Println("map2:", map2)
    fmt.Printf("map3: %v len:%v\n", map3, len(map3))

    //3.遍历
    fmt.Printf("%-12s", "map2:")
    //遍历map
    for key, value := range map2 {
        fmt.Printf("%v:%v ", key, value)
    }
    fmt.Println()
    fmt.Printf("%-12s", "map2 key:")
    //遍历key
    for key := range map2 {
        fmt.Print(key, " ")
    }
    fmt.Println()
    fmt.Printf("%-12s", "map2 value:")
    //遍历value
    for _, value := range map2 {
        fmt.Print(value, " ")
    }
    fmt.Println()

    //4.CRUD
    //增
    map3[1] = "猫"
    map3[2] = "狗"
    map3[3] = "兔子"
    map3[4] = "乌龟"
    fmt.Println("增: map3:", map3)
    //删
    delete(map3, 3)
    fmt.Println("删: map3:", map3)
    //改
    map3[4] = "Tom"
    fmt.Println("改: map3:", map3)
    //查
    fmt.Println("查: map3:", map3[1], map3[2], map3[4])

    //5.判断某个键是否存在
    v1, ok1 := map2[1]
    if ok1 {
        fmt.Println("key:1存在,其对应的值为: ", v1)
    } else {
        fmt.Println("key:1不存在")
    }
    v2, ok2 := map2[4]
    if ok2 {
        fmt.Println("key:4存在,其对应的值为: ", v2)
    } else {
        fmt.Println("key:4不存在")
    }
}

package main

import "fmt"

//1.定义
type Animaler interface {
	Move()
	Say()
}

type Animal struct {
	Name string
	Feet int
}

func newAnimal(name string, feet int) Animal {
	return Animal{
		Name: name,
		Feet: feet,
	}
}

//2.实现接口（实现接口里的所有方法）
//2.1实现接口的方法的接收者是值类型，创建接口变量时，不管是结构体类型还是对应的结构体指针类型的变量都可以赋值给该接口变量
func (a Animal) Move() {
	fmt.Println(a.Name, "会动！")
}

//2.2实现接口的方法的接收者是指针类型，创建接口变量时，只有结构体指针类型的变量可以赋值给该接口变量，结构体类型不行
func (a *Animal) Say() {
	fmt.Println(a.Name, "会叫~")
}

type Dog struct {
	Animal
}

func newDog(name string, feet int) Dog {
	return Dog{
		newAnimal(name, feet),
	}
}

func (d Dog) Say() {
	fmt.Println(d.Name, ":小奶狗来喽，汪汪汪~")
}

type Cat struct {
	Animal
}

func newCat(name string, feet int) Cat {
	return Cat{
		newAnimal(name, feet),
	}
}

func (c Cat) Say() {
	fmt.Println(c.Name, "会喵喵喵的叫~")
}

type Bird struct {
	Animal
}

func newBird(name string, feet int) *Bird {
	return &Bird{
		newAnimal(name, feet),
	}
}

//3.只有接口可以实现一个函数接收多种类型的参数
func Hungry(a Animaler) {
	a.Say()
}

func main() {
	//4.多态
	var dog1 Animaler = newDog("旺财", 4)
	fmt.Printf("%T,%v\n", dog1, dog1)
	dog1.Move()
	dog1.Say()
	Hungry(dog1)
	var cat1 Animaler = newCat("小猫", 4)
	fmt.Printf("%T,%v\n", cat1, cat1)
	cat1.Move()
	cat1.Say()
	Hungry(cat1)
	var bird1 Animaler = newBird("小鸟", 2)
	fmt.Printf("%T,%v\n", bird1, bird1)
	bird1.Move()
	bird1.Say()
	Hungry(bird1)
}

package main

import (
	"fmt"
	"sync"
)

// 5.使用 sync.WaitGroup 等待多个 goroutine 执行完成
// 5.1创建 WaitGroup 全局变量
var wg sync.WaitGroup

func main() {
	wg.Add(1)
	//1.用 go 关键字启动 goroutine
	go hello() //2.启动单个 goroutine
	fmt.Println("你好")
	//3.使用 time.Sleep 等待单个 goroutine 执行完成
	//time.Sleep(time.Second)
	//4.启动多个 goroutine
	for i := 0; i < 10; i++ {
		//5.2每启动一个 goroutine，wg 就 +1
		wg.Add(1)
		go hellos(i)
	}
	//5.4等待所有的 goroutine 结束
	wg.Wait()
}

func hello() {
	fmt.Println("hello")
	wg.Done()
}

func hellos(i int) {
	//5.3每完成一个 goroutine，wg 就 -1
	defer wg.Done()
	fmt.Println("hello", i)
}

package main

import (
	"fmt"
	"sync"
)

// 零协程：只输出 0
func zeroRoutine(chZero chan struct{}, done chan struct{}, wg *sync.WaitGroup) {
	defer wg.Done()
	for {
		<-chZero
		fmt.Print(0)
		done <- struct{}{}
	}
}

// 奇数协程：输出 1,3,5...
func oddRoutine(chOdd chan struct{}, done chan struct{}, n int, wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 1; i <= n; i += 2 {
		<-chOdd
		fmt.Print(i)
		done <- struct{}{}
	}
}

// 偶数协程：输出 2,4,6...
func evenRoutine(chEven chan struct{}, done chan struct{}, n int, wg *sync.WaitGroup) {
	defer wg.Done()
	for i := 2; i <= n; i += 2 {
		<-chEven
		fmt.Print(i)
		done <- struct{}{}
	}
}

func main() {
	n := 6 // 可修改为任意正整数

	// 创建三个控制 channel
	chZero := make(chan struct{})
	chOdd := make(chan struct{})
	chEven := make(chan struct{})
	done := make(chan struct{}) // 用于等待上一次输出完成

	var wg sync.WaitGroup
	wg.Add(3)

	// 启动三个协程
	go zeroRoutine(chZero, done, &wg)
	go oddRoutine(chOdd, done, n, &wg)
	go evenRoutine(chEven, done, n, &wg)

	// 主协程控制输出顺序
	for i := 1; i <= n; i++ {
		// 输出 0
		chZero <- struct{}{}
		<-done

		if i%2 == 1 { // 奇数位输出奇数
			chOdd <- struct{}{}
		} else { // 偶数位输出偶数
			chEven <- struct{}{}
		}
		<-done
	}

	// 程序结束（实际需优雅退出，这里简化处理）
	// 实际生产环境需要通知协程退出，但此题目只需输出一次，main 结束即可
	// 为避免 goroutine 泄漏，可以 close 所有 channel
	close(chZero)
	close(chOdd)
	close(chEven)
	close(done)

	// 等待协程结束（可选，因 main 已结束）
	// wg.Wait()
	fmt.Println() // 换行
}
